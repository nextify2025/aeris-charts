## 纯计算与增量运行时

基于数值切片的纯技术指标计算。预热缺口是显式的。依赖约定的公式采用此处拥有的类型化参数：EMA 族/RSI 的种子（`Sma`，即 TradingView/TA-Lib 的默认值；或 `FirstValue`，即 通达信/同花顺 的 `EMA(X,N)`/`SMA(X,N,M)` 约定）、MACD 柱状图乘数（1，或用于 `(DIF-DEA)*2` 的 2），以及布林带偏差估计量（总体或样本）；`IndicatorConvention` 只负责把预设映射到这些值。KDJ 使用带窗口的 RSV，其 K/D 平滑采用 `SMA(X,N,1)`，起始于类型化的 `KdjSeed`：教科书式的 50（在完整的 N 行窗口之后，默认），或公式语言式起始（China 预设选用此项）：在行数不足 N 时对可用行计算 RSV，且 `Y0 = X0`，因此数值自第 0 行起即有。`tests/platform_values.rs` 固定了已验证的平台规则（中国式 MACD、总体 σ 布林带、公式语言式 KDJ 起始，以及教科书式起始在 `convergence_rows` 之后的收敛），所用为确定性的合成序列，预期值独立计算得出；与平台针对真实柱发布数值的对比是在仓库之外完成的，该数据未提交。

每个运行时还按输出报告其预热行数和收敛跨度（直到每个递归种子的权重低于 0.1% 所需的行数；对时间锚定和路径依赖的公式则为无）；引擎沿指标链对它们求和。空白数据源行（收盘、最高或最低非有限）绝不进入公式状态：递归运行时（包括 KLineChart 运行时）就地跳过它们并输出 NaN；而无状态窗口公式若在其读取的行中遇到空白数据，则在有界的压缩窗口（其回看长度加上变更的尾部）上求值，并把 NaN 散回空白数据行，因此每个值都等于不含这些行时计算出的值。除干净的全量重算函数外，它还拥有用于追加、当前柱替换和从某索引重建的显式逐公式滚动状态。有界窗口公式不保留与源长度相关的状态；递归公式保留尾部状态，并每 1,024 个源行保留一个检查点，在历史修正之后从最近的前一个检查点重新计算。在最后一行之前保留的状态，无论同一次重建是否还追加行，都可用于恢复对该行的替换，因此在一个批量中收盘当前柱并开启下一根柱时，绝不会退回到检查点。因此，每种内置指标对当前柱替换、追加，或在一次重建中两者兼有的开销，都以其窗口而非历史长度为界：窗口公式（移动平均、标准差、CCI、Williams %R、动量、变动率、Donchian、Ichimoku、CMF、MFI、成交量）只对变更的输出行求值，每行各自按其周期计算；而 Stochastic RSI（Wilder RSI 状态加上保留的最近若干 RSI 值的尾部窗口，与 Stochastic `%D` 相同）、枢轴点（当前进行中与前一个交易日的交易时段）和 ZigZag（其锚点、方向和临时极值）则是就地跳过空白数据的递归状态。

ZigZag 会把转折点回写到更早的行，因此尾部重建只有在改变其唯一的开放转折点（它移动或恢复的临时端点，或它写入或清除的首方向锚点）的值时，才会重新输出回溯到该点的各行，这使其以自上一个已确认转折点以来的行数为界；未触及该点的尾部修订只会触及正在形成的柱，而历史修复则从其所恢复状态的开放转折点起重新输出。`last_work_rows` 报告每次重建实际求值的行数。成交量和成交额列可以比源行短；越过其末尾的行采用各公式的缺失权重回退值（VWAP、VWAP 带和 VWMA 为单位权重，OBV、CMF、MFI、成交量以及广度层的八个成交量研究为零，按成交额加权的 VWAP 为无成交），这与引擎的时间戳对齐回退值相等。稀疏检查点向量为写时复制，因此宿主可以事务性地克隆递归状态，而无需在常规尾部工作期间深拷贝保留的历史。与宿主无关的带索引的 EMA、ATR、交易时段 VWAP、RSI、MACD 和 Stochastic 状态接受由回调提供的可选样本，使非图表的 Rust 宿主只需惰性地转换为脏后缀而重放的规范行。`None` 是硬重置；递归重放可以从更早的稀疏检查点开始，而写入方只接收所请求的后缀。

Stochastic 另外只保留 `%D` 尾部替换所需的有界尾部 `%K` 窗口（Stochastic RSI 同样保留其最近的 RSI 值），而无法从中恢复的重建（包括截断）会重放足够多的更早的行，以重新填满窗口，供之后对新的最后一行的替换读取；其带窗口的最高/最低扫描仍以配置的 `%K` 周期为界，而非源历史长度。派生值使用短生命周期的传输缓冲区，这些缓冲区移入或更新引擎的规范输出系列，并在部分修复之后限定其容量上限。`aeris_charts_indicators` 不了解图表、窗格、渲染、WebAssembly 或 GPUI。

日历周期（VWAP 的交易时段/每周/每月重置、枢轴点的交易时段，以及 `exchange` 日历策略下时段研究的日、周、月与开盘区间锚点）以调用方提供的交易日映射为键；`aeris_charts_indicators` 不了解时区，且每周周期从周一开始。图表运行时传入引擎的交易所交易日，而全量重算函数则沿用 UTC 日。`VwapReset::period_key` 暴露重置键本身，因此图表几何会恰好在数值重置处断开线条。

## KLineChart 公式与一致性

`klinechart` 包含 27 个内置 KLineChart 指标，移植自 KLineChart v10.0.3（在 `NOTICE` 中注明来源），与由 KLineChart 自身代码生成的夹具（`tools/klinechart_parity`）逐位一致。输出为列，KLineChart 未设值之处为 `None`；`Indicator` 是可绑定形式（模板加 calcParams、输出键与标题、图形类型、放置位置、值格式、成交量需求，以及每个输出的预热行）。其增量运行时每次对每个公式推进一个有效行，状态为由检查点保存的 `Copy` 状态，存放在内置研究所用的同一个稀疏 `RecursiveHistory` 中（每 1,024 行一个检查点，外加两个尾部状态），因此当前柱替换或追加的开销取决于公式的窗口而非历史长度，而历史修复至多重放变更行之前的 1,023 行。运行和保持 KLineChart 先加、再除、后减的顺序，因此每个值都保持逐位一致；对公式自身输出取移动平均时，离开窗口的值取自同一状态中保存的产生该输出的阶段的滞后副本（OBV、PSY、TRIX、DMA、DMI、VR、CR），或者在该输出是两个输入行的纯函数时从窗口重新计算（MTM、ROC、EMV）。

空白数据源行（收盘、最高或最低非有限）通过一个有界的压缩窗口被就地跳过，输出为 NaN 且状态不变；该窗口以每块 4,096 个源行为单位重放（每列为一块加上公式的回看长度，在部分修复后收缩回去），因此窗口与滞后只计入带有样本的行，每个值都等于不含空白数据行时计算出的值。全序列函数遵循同一条规则：递归与累计函数是同一批步进器的折叠，而步进器自身在非有限样本上不推进（`ema_step`、`smma_step`、`indexed_rsi_step`、`atr_step`、`keltner_step`、`adx_dmi_step` 等，纵深防御，与运行时调用处的 `whitespace_row` 检查重复但无害）；窗口与滞后函数在入口经 `without_gap_rows` 守卫：价格列含非有限行时，先删去这些行（与 `rebuild_compacted` 共用 `compact_column`），在剩余行上求值，再把 NaN 散回被删去的行，因此 `aeris_charts_indicators::sma(有缺口的序列)` 与图表的值相同；输入全部有限时不复制，原地求值。运行时执行的算术因此就是一致性夹具所固定的算术。检查点和空白数据窗口计入指标运行时的字节数。`Indicator::extra_convergence_rows` 报告每个指标读取多少历史：带窗口的公式在预热之外为无，各项会读取前一根柱的窗口为一行，递归平滑、运行总计和路径依赖的 SAR 则为 `None`；一项测试通过丢弃最旧的行来度量它。

`klinechart` 模块移植了 KLineChart v10.0.3 的 27 个内置指标（MA, EMA, SMA, BBI, VOL, MACD, BOLL, KDJ, RSI, BIAS, BRAR, CCI, CR, DMA, DMI, EMV, MTM, OBV, PVT, PSY, ROC, SAR, TRIX, VR, WR, AO, AVP），遵循中国大陆和香港图表软件的约定：加倍的 MACD 柱状图、以 SMA 为种子的 EMA、加权的 `SMA(X, N, M)`，以及以 50 为种子的 KDJ。每个移植都以相同的顺序重复 KLineChart 的算术，因此 `tests/klinechart_parity.rs` 将每个值与 KLineChart 自身的 `calc` 输出逐位比较（`tools/klinechart_parity` 重新生成该夹具）。`klinechart::Indicator` 是可绑定形式：模板加 `calcParams`、输出键与标题、图形类型、默认放置位置、值格式、成交量需求，以及每个输出仅由参数决定的预热行。其运行时如上所述从检查点状态每次推进一个有效行；输出是因果的，因此只输出所请求的后缀，预热之后仍未设值的行变为 NaN 空白数据。这些公式及其测试是 Apache-2.0 的 KLineChart 衍生物，已在模块文档中注明来源。

## 成交量分布

可见范围成交量分布在 `aeris_charts_indicators` 中使用纯粹的两遍 OHLCV 分箱计算：均匀的最高/最低价区间重叠、按蜡烛方向拆分的看涨/看跌成交量、确定性的控制点（POC）与连续价值区域，工作量为 `O(visible bars + rows)`，且至多 512 行。它不声称达到逐价位 Tick 的精度。

成交量分布指标将一个 OHLC 价格系列按精确时间戳绑定到一个独立的标量成交量系列。引擎在原生图元状态中拥有至多 16 个分布句柄、它们的选项以及有界的分箱缓存。在帧构建之前（或显式快照读取之前），它只刷新那些源代次、可见源行区间、分箱参数或最小价格变动发生了变化的分布。移除任一依赖项就会移除该句柄。共享的帧几何在每一行内堆叠看涨与看跌成交量，使每一行紧贴源窗格的右边缘，对价值区域使用更强的行颜色，并且只绘制实线 POC 标记，且不扩展自动缩放范围；每个执行器消费的都是这同一组有序图元。这些价格分布没有合成的时间序列输出，且仅限运行时，不在 V1 标量指标工作区持久化范围之内。宿主在恢复数据后重新创建它们。

## 周期分布、TPO 与分布绘图

B7 的分布查询路径通过引擎读取规范的已分类[成交带](../engine/market-data.md#共享成交流与唯一写入者)或 OHLCV K 线。成交带分布按 tick 价位保留 bid、ask、未知与 delta 成交量；K 线分布则会标明其为近似结果。周期分布与 TPO 使用宿主提供的有序、互不相交的 UTC 边界。具有相同交易时段标识的相邻周期边界构成一个复合分布；边界之间的空隙不贡献任何行或动态演变点。成交带的裸价位止于同一 tick 价位上的第一笔后续成交；K 线价位则在后续某个 OHLC 区间包含该精确价格时终止。

浏览器包通过 WASM 暴露这些引擎查询，并在价格系列上安装有界的周期分布呈现。引擎根据规范的 K 线或成交带计算每个由宿主定义的周期，在原生图元状态中保留源绑定，并把 bid/ask、delta 或总量柱连同 POC 与价值区域标记转换到该系列的共享帧图层中。呈现可以把 POC 与价值区域价位从周期结束处延伸到其后的第一次触及。共享查询在一次有序的源扫描中解析所有请求的价位。K 线与成交带的修正会使所绑定系列的图层失效，而移除 K 线依赖项会释放其呈现句柄。呈现句柄总共至多预留 32,768 个分布行，并为每个成交带周期按完整的 2,048 行成交带上限预留，即使当前成交带的价位更少也是如此。可选的成交带与 K 线动态演变路径在整个呈现中至多采样 2,048 个 POC/价值区域点，并将其转换为共享折线。`aeris_charts_indicators` 在该周期最终的固定价格网格上累积 K 线 OHLCV；这使历史价位在 K 线区间扩大时仍可相互比较，但它仍然是 OHLCV 近似。周期查询在其自身的总上限内保留详细的动态演变历史；当这些路径被隐藏时，常规帧构建会省略该历史。

固定区间分布、锚定分布与锚定 VWAP 绘图种类绑定一个经过校验的源，并把其几何转换到共同的有序帧中；浏览器的绘图种类映射与引擎工具目录使用相同的 [wire id](../engine/drawing-families.md#wire-id-与注册表)。

具有相同宿主交易时段标识的连续 TPO 边界合并为一个周期索引连续的分布；不同的标识会拆分分布，而所提供的分段之间的空隙不会添加合成周期。初始平衡区从第一个分段起计算周期。TPO 呈现是附着在其 OHLC 源系列上的有界原生图元。它的字母与色块模式、价值区域与单一印记颜色、POC 与初始平衡区线条都被转换到共享的有序帧中，因此每个执行器绘制的都是相同的单元格。查询输出既在整个请求范围内有界，也在每个分布内有界；当各个单元格超出详细呈现的预算时，帧会切换为紧凑色块。

价格与成交量修正只会使绑定到该系列的绘图失效；成交带更新与回放定位会使绑定到该流的绘图失效，即使没有附着任何足迹图系列也是如此。只要有分布绘图引用某条流，该流就保持为使用中，因此移除操作不会留下一个缺失成交带的存活绘图。

## 引擎绑定与输出

指标绑定把其公开定义、紧凑的私有运行时和普通规范输出系列彼此分离。每个标量输出都从其第一个值开始（所有者决定 Q-H，上游 `0dcca70` 的输出形状）：内置、结构、时段与自定义研究共用一个输出写入函数 `store_indicator_output`，它不保存开头的 NaN 行；市场结构、公允价值缺口与订单块的锚定输出例外，保留每个源时间。重写的第一行落在输出当前起点或其之前（或输出为空）时，起点可能移动，因此改为整列替换，且只用重写的行构建（起点之前没有行）；只有完整重建或起点确实移动时才向依赖者报告 `full_replace`（它们的行号被重新编号），空输出保持为空时不写入、不报告，因此预热中或全空白的源（订单流图表的空白主系列）每个 Tick 的工作量仍有界。其他更新只写入重写的行；被替换的列按精确大小保存，使批量安装后的首次追加仍只让每列增长一次。本仓库只在输出层实现这一形状，不采用上游按第一个有限收盘价切片输入并重置运行时的做法（那会在每次修正时重新分配，并在全空白源上每个 Tick 做一次 O(n) 扫描）。`indicator_info().warmup_bars` 仍按无缺口的源度量，源以空白数据开头时输出的第一行会晚于它。其运行时覆盖源直至数据末端（最后一个真实行之后一位，且至少保持到上一次重建的数据末端），因此尾部的空白数据行（例如预先安装的交易时段槽位）既不会被评估也不会被重写：它们的输出保持空白，递归状态在正在形成的槽位被填充或变化时从保留的尾部状态恢复，而 `DataLayer::update_single_aligned_within` 只写入对齐输出中发生变化的行，因此填充或修订一个槽位的代价如同追加，只是一个窗口的代价。稀疏的运行时检查点与源行位置以及源和可选成交量/成交额系列的代次绑定。成交量与成交额列按时间戳与源行配对，因此其中一列的变化会从其最后一个未变化时间戳之后的第一个源行恢复，而不是从它自己的行索引恢复。尾部变更只推进依赖该源的绑定，并只安装发生变化的输出行；历史变更从最近的有效检查点恢复并替换受影响的输出后缀，而截断或完整替换则执行干净重建。五输出的 EMA 彩带是一个绑定，每个配置的周期各有一个独立设置检查点的递归 EMA 状态。其原子的周期更新保留所有输出标识和呈现，只重建一次五个数值列，并将由此产生的变化传播到依赖的指标。被移除的源/输出系列会同时丢弃该绑定及其运行时状态。VWAP 带对加权基准、总体偏差和百分比带使用相同的稀疏检查点边界，并使用由图表的交易所交易日派生、由引擎拥有的交易时段/每周/每月重置键。VWAP 绑定还可以携带时间戳对齐的成交额（amount）系列；此时它会在相同的重置键上报告分时均价 `sum(amount) / sum(volume)`，并跳过没有正成交量或有限成交额的行。约定预设在宿主边界处被展开为显式的 `IndicatorKind` 参数，因此绑定、元数据和持久化绝不保存预设名称。

KLineChart 绑定（`IndicatorKind::KLineChart`，持久化为 `{"kind": "klinechart", "indicator": ...}`）复用同一套绑定、别名、持久化与 schema 路径。其呈现由引擎拥有：采用 KLineChart 五色调色板的 1px 线条，`VOL`/`MACD`/`AO` 的柱体以直方图呈现，`SAR` 以仅含标记的圆点呈现，并对运行时重写的行重新计算逐行颜色（绝不涉及预先安装的交易时段在其数据末尾之后保留的空白数据槽位），价格类模板位于源窗格，其余每个模板位于各自的振荡器窗格，且不显示价格轴数值标签。KLineChart 会为上涨的 MACD 与 AO 柱体描边；Aeris 直方图没有描边样式，因此这些柱体改为以较浅的 alpha 填充。`VOL`、`OBV`、`PVT`、`EMV` 与 `VR` 需要一个独立的标量成交量系列（缺失的时间戳使用 KLineChart 自身的默认值，PVT 为 1，其余为 0）；`AVP` 将成交额读取为某个标量源系列的值，并从其成交量系列读取成交量。浏览器宿主通过包中的 `add_klinechart_indicator` 创建它们；该函数通过与其他研究相同的通用 `add_indicator` WebAssembly 入口发送类型化定义，且不保留模板列表的副本：模板名称、默认值、公式、参数与源的校验以及呈现全部保留在引擎中，引擎会拒绝无效或未知的定义且不产生任何输出（表现为 `invalid_options`）。包的 `indicator_kind` 包含 `klinechart_*` 种类，`indicator_info().parameters.klinechart` 返回该定义。

指标输出元数据是增量式的，且对绑定而言是完整的：第一个输出的单调系列标识即为稳定的绑定标识；每个输出都报告完整的结构化参数、源、可选的 VWAP/VWMA 成交量源与 VWAP 成交额源、稳定的输出名称、索引与数量，以及其预热行数与收敛行数（这两者均以根价格源为基准度量，并穿过所有链式指标源）。原生宿主还可以按确定性的创建/依赖顺序为每个存活绑定枚举一个类型化定义，并通过通用 `IndicatorKind` 入口（`add_indicator_kind_with_sources`）重建它，同时在此过程中重映射源、成交量源、成交额源及有序输出的标识。该定义快照不包含运行时计算状态。标量系列还可以携带由引擎拥有的、与渲染器无关的语义呈现：固定阈值区域会转换为规范的半透明振荡器通道加点状边界线，动量直方图复用规范的四态市场调色板，并将空白数据视为重置。宿主声明这些语义，但绝不接收或保留渲染图元或调色板逻辑。宿主根据绑定元数据对图例分组并渲染；指标值仍通过普通的图表值快照获得。研究绑定还额外携带一个在引擎边界处选定的类型化标量输入（`open`、`high`、`low`、`close`、`hl2`、`hlc3`、`ohlc4` 或 `hlcc4`）；聚合输入绝不会成为规范系列：每个绑定将其聚合列保存为私有运行时状态（计入指标运行时内存），并且仅从重建的第一个变更行起重新派生，因此一个 Tick 只派生一行，而不是整段历史。

聚合列只属于一个绑定，绝不在绑定之间共享。其大小为行数加上有界的尾部备用容量（行数的八分之一再加一个固定下限），因此批量安装后的首次追加不会使其重新分配，之后的增长也保持在该界限内；当其容量超过该大小的两倍时，从第 0 行开始的重建会将其释放，运行时内存统计的是其容量而不是其长度。下文的成交量与成交额对齐列不在该容量策略之内，研究输出列同样如此：它们的运行时恰好为其产生的行数预留空间，因此批量安装后在源之后的首次追加仍会让每个输出各增长一次（这是该预留处已记录的延后事项，待决定每个输出要保留多少备用容量）。多输入绑定按精确时间戳而非行位置，将成交量与成交额输入同源行配对。当一条时间线是另一条的前缀时（时间线相同，或 K 线与其成交量以任一顺序推送一根新柱），权重列按原样借用，仅比较新增的共享行；时间线发生分叉时，则保留由绑定拥有的对齐列，并对缺失时间戳采用文档所述的回退值（VWAP、VWAP 带与 VWMA 为单位权重，OBV、CMF、MFI、成交量与广度层的八个成交量研究为零，成交额为无成交），该列同样仅从第一个变更行起重新派生。

`last_indicator_work_rows` 按绑定汇总其最近一次重建的公式行数与派生输入行数。每个输出还会暴露一个紧凑的、由引擎拥有的样式快照（可见性、线条、标记、面积与方向颜色），并接受经过校验的原子样式替换，因此逐输出的样式可在宿主持久化后保留，而无需按种类专门重建。WASM 宿主可以按指标种类查询同一份有界的参数/输出 schema，因此属性面板无需重复引擎定义。按名称的查询由引擎拥有的 `IndicatorKind::schema_definition(kind, period, deviation)` 解析为定义：隐式查询（`period` 14、`deviation` 2）返回每个研究自己的规范默认值（MACD 12/26/9、Stochastic `%D` 3、SuperTrend 3、EMA 彩带 5/10/20/50/200、VWAP 带 σ 1、KDJ 9/3/3，以及广度层各研究的默认值），其他 `period` 仍按旧的单周期替换规则；带种子的种类描述教科书式的 SMA 种子，MACD 的直方图乘数为 1，布林带为总体估计量，`klinechart_*` 名称回退到对应 KLineChart 模板的默认参数，未知名称为无。WASM 的 `indicator_schema_json` 只委托给它，不再保留自己的映射表。

## 广度层指标

广度层共 29 个内置研究。上游 `2f62875` 新增 19 个，沿用上文的同一套绑定、规范输出系列、元数据、样式与持久化路径：Aroon（上/下两个输出）、Awesome Oscillator（AO）、DPO、Chande Momentum（CMO）、布林带指标（%B 与 BandWidth）、包络线（Envelopes，SMA 或 EMA 基线）、ALMA、累积/派发（A/D）、价量趋势（PVT）、Chaikin Oscillator、相对成交量、成交量振荡器（PVO、信号线与柱状图）、Elder Force、简易波动（EOM）、历史波动率（HV）、TRIX（线与信号线）、Coppock Curve、Fisher Transform（线与触发线）和 Ultimate Oscillator；上游 `9dd8cff` 补齐其余 10 个，见下文[广度层补全](#广度层补全)。

- **窗口类**：Aroon 以 `period` 加当前柱为窗口，相等极值取最新者；AO 为中位价 SMA(5) 减 SMA(34)，从第 33 行起有值；DPO 用滞后 `period / 2 + 1` 柱的价格减去当前 SMA；CMO 为窗口内有符号与绝对收盘变动之比；布林带指标只采用总体标准差；SMA 包络线、ALMA（保留按 `period`、`offset`、`sigma` 归一化的高斯权重）、相对成交量（当前非负成交量除以此前 `period` 根柱的均值，不含当前柱；零基线为空缺）、EOM（中位价位移乘以柱区间再除以按 `divisor` 归一化的成交量，窗口内只要有一根零成交量柱即为空缺）、Coppock Curve 与 Ultimate Oscillator（4:2:1 加权的三窗口买压/真实波幅比，零区间窗口为空缺）都是无状态窗口，每个输出行按其窗口求值。历史波动率同样按窗口求值：对 `period` 个正价格对数收益求样本标准差，乘以 `sqrt(annualization)` 并以百分比报告。上游以滚动和与平方和的递归检查点实现它；本仓库改为窗口求值，使其能走空白数据压缩路径，且长历史不会累积抵消误差，尾部更新的代价仍为一个窗口。DPO 与 CMO 同样在每个受影响的行上重新计算其窗口，不保留滑动和，因此已离开窗口的值不会残留舍入误差；布林带指标的宽度取舍入后的上下轨之差（`upper - lower`），与全序列函数一致（上游 `4cfea16`）。
- **递归类**：EMA 包络线、Chaikin Oscillator（A/D 的快慢 EMA 之差）、成交量振荡器（非负成交量的快慢 EMA 之百分比差与其 EMA 信号线）、Elder Force（收盘变动乘以非负成交量的 EMA，第一根有效柱只提供前一收盘价）、TRIX（三重 EMA 的一柱百分比变动与其 EMA 信号线；三重 EMA 为零时该行为空缺并重置信号线）和 Fisher Transform（中位价在窗口最高/最低之间的位置经截断递推，触发线为上一 Fisher 值；窗口含非有限值时重置递推）保存在与其他递归研究相同的稀疏检查点中。A/D 与 PVT 是累计量，同样使用检查点。这些新 EMA 一律以前 N 个样本的 SMA 起始，没有 `seed` 参数，因此 `IndicatorConvention::China` 不会改变它们（`ponytail:` 延后项）。

**空白数据**。全部 29 个研究都遵循“空白数据行如同不存在”的契约：窗口类研究登记在 `compaction_lookback` 中，遇到空白数据时在压缩窗口上求值（Ultimate Oscillator 的回看比其预热多一行，因为窗口第一根柱还要读取前一收盘价）；递归与累计类研究在空白数据行输出 NaN 且不触碰状态，Elder Force 用状态里的 `initialized` 标记代替“行号大于 0”，Fisher Transform 以 `valid_extremes` 取最近 `period` 个有样本行的极值。`compaction_lookback` 不再以通配分支结尾，新增种类必须在编译期决定其空白数据处理方式。`whitespace_test_states()`、`tests/incremental_equivalence.rs` 以及引擎的 `every_indicator_kind()`、`every_indicator_kind_with_conventions()` 和批量/单条更新测试都覆盖了全部 29 个种类。

**与上游空白规则的对照**（上游 `0da249d`..`85bc10b`，经合并 `85bc10b` 的提交引入；所有者决定 Q-G）。双方都以“缺失的源行不是样本”为起点，对递归与累计类研究（EMA 族、RSI/Stochastic RSI、MACD、TRIX、ATR、ADX、SuperTrend、PSAR、Keltner、ATR 带、Elder Force、OBV、A/D、PVT、Chaikin、VWAP 与 VWAP 带、TSI、KAMA、Mass Index、Fisher、McGinley）结果相同：从最后一个有效样本继续，预热只计入有效样本，空白行为 NaN。区别在窗口与滞后类：上游在缺口仍位于物理窗口内时让输出保持空白（宽度一般为 `period`；Momentum、ROC、CMO、HV、Aroon、Vortex、Choppiness、EOM 与相对成交量为 `period + 1`；Coppock 为长周期加平滑；KST 为滞后加平滑减一，信号线再加信号窗口减一；AO 为 34；Ichimoku 为 9/26/26/52；Ultimate Oscillator 为三个周期之和加一），窗口移出缺口后才等于删去缺口行的值；本仓库从缺口后的第一行起即给出删去缺口行的值，窗口始终跨越最近 N 个有效行。本仓库的结果是上游的严格超集：上游有值处二者相同。因此本仓库不需要上游为该规则所加的补丁：Stochastic 的 `StochasticCarry` 与 Fisher 的 `valid_rows` 队列（本仓库以 `valid_extremes` 加 `Copy` 累加器得到相同的压缩值，长缺口后的重扫为每行 O(k + 缺口)）、Coppock 与 KST 的连续性扫描（压缩后恒为真）、零成交量 CMF 在缺口旁的屏蔽（压缩窗口不含缺口，零成交量窗口为 0）、以及 HV 的滑动和重新居中（本仓库按窗口求值，并以窗口第一个收益为偏移，常数收益得到精确的 0）。其余规则：有限的倒挂柱（最高低于最低）是观测值，除 Klinger 与 Mass Index 外的所有种类照常处理（上游 `dadaa4b` 撤回了把它当作缺口的临时规则）；Klinger 与 Mass Index 沿用上游步进函数的文本，在这样的柱上不输出、也不重置（见[广度层补全](#广度层补全)）；`whitespace_row` 对收盘、最高、最低三者使用同一个“非有限”判定（±∞ 也是空白），不采用上游按种类区分的必需字段——图表核心不会交出部分为 NaN 的行，这一区别只影响直接使用 `IndicatorInput` 的 Rust 宿主。RSI 运行时的检查点改为保存 `IndexedRsiState`（上一个有效收盘价、已计的变动数与 Wilder 均值），修复跨越任意长的缺口都无需向后扫描，代价是每个检查点更大，RSI 的 `runtime_bytes` 上界相应由 32 KiB 放宽到 64 KiB（并要求不超过 2 × 检查点数 × `size_of::<Checkpoint<IndexedRsiState>>()`）。本仓库与上游文本的有意分歧集中记在 `compaction_lookback` 旁的 `ponytail:` 分歧台账中。

**收敛**。窗口类研究的 `convergence_rows` 等于预热；A/D 与 PVT 依赖整条已加载路径，为 `None`；Chaikin 的 A/D 水平在两条 EMA 之差中相互抵消（EMA 与其 SMA 种子都是线性的），因此只需预热加上较慢 EMA 的衰减行数；成交量振荡器与 MACD 的规则相同；Elder Force 与 EMA 包络线为预热加一次 EMA 衰减；TRIX 线为预热加三次衰减，信号线再加信号 EMA 的衰减；Fisher Transform 为预热加上 0.67 与 0.5 两级递推各自降到 0.1% 以下所需的行数。

**成交量**。八个成交量研究（A/D、PVT、Chaikin、Klinger、相对成交量、成交量振荡器、Elder Force、EOM）与 OBV、CMF、MFI 一样需要独立的标量 `volume_source`，并把成交量序列缺失的源时间戳按零成交量处理（引擎 `missing_volume()` 的 `0.0` 分支）。

**呈现**。AO 的唯一输出与成交量振荡器的第三个输出是动量柱状图，复用引擎的四态市场调色板，空白数据重置比较；逐柱颜色从直方图系列实际的第一行开始（输出从第一个值开始，源以空白数据开头时晚于静态预热行），与 MACD 相同；整列被替换时按存储的值重新着色，否则只为重写的行着色。布林带指标把 %B 与 BandWidth 放在两个振荡器窗格中，因为二者单位不同。包络线与布林带共用 `band_fill_companion` 的带状填充帧路径；包络线和 ALMA 位于价格窗格。schema 新增 `IndicatorParameterType::Boolean`（包络线的 `exponential`），`INDICATOR_SCHEMA_REVISION` 因此升为 3。

**与同名 KLineChart 模板的区别**。AO、PVT、TRIX 与 EMV 在 [KLineChart 模板](#klinechart-公式与一致性)中也有同名公式，两者并存且公式不同；KLineChart 绑定的图例行标题带 `KLineChart` 前缀（例如 `KLineChart PVT`），演示目录中的条目也以 `KLineChart` 开头。只有图例行与目录加前缀：各输出系列的 `title` 沿用模板自身的输出名以保持与 KLineChart 的显示一致，因此内置 PVT 与模板 PVT 的系列标题都是 `PVT`，二者由 `indicator_info().kind`（`price_volume_trend` 与 `klinechart_pvt`）区分：

| 内置研究 | KLineChart 模板 | 区别 |
| --- | --- | --- |
| `awesome_oscillator`：固定 5/34 | `klinechart_ao`：可配置 `short`/`long`（默认 5/34） | 核心同为中位价 SMA 之差；内置研究按动量四态调色板着色，模板按 KLineChart 的涨跌柱呈现，并以运行和计算均值 |

### 广度层补全

上游 `9dd8cff`（含 `42fcca4`、`0bc50ca`）补齐其余 10 个广度研究，绑定、输出、样式、持久化与 schema 路径与上文相同。括号内为隐式 schema 查询与 TS 方法的默认参数。

| 种类 | 公式 | 输出（顺序） | 位置 |
| --- | --- | --- | --- |
| `kst`（ROC 10/15/20/30，SMA 10/10/10/15，信号 9） | 四个百分比 ROC 各取 SMA，按 1:2:3:4 加权求和；信号线为 KST 的 SMA | `KST`、`Signal` | 振荡器窗格 |
| `tsi`（25/13/13） | 收盘变动的双重 EMA 除以其绝对值的双重 EMA，乘以 100 并截断到 ±100；变动恒为零时为 0；信号线为 TSI 的 EMA | `TSI`、`Signal` | 振荡器窗格 |
| `mass_index`（EMA 9，求和 25） | 最高-最低区间的 EMA 与其二次 EMA 之比，对最近 `sum_period` 个比值求和；二次 EMA 为零时该比值为空缺 | `Mass Index` | 振荡器窗格 |
| `vortex`（14） | `period` 根柱的 VM+ 与 VM- 之和分别除以真实波幅之和 | `VI+`、`VI-` | 振荡器窗格 |
| `klinger`（34/55/13，需要 `volume_source`） | 以最高+最低+收盘的变化定趋势，趋势反转时重新累计区间；成交量力量的快慢 EMA 之差，信号线为其 EMA；区间为零时力量为零 | `Klinger`、`Signal` | 振荡器窗格 |
| `kama`（10/2/30） | 前 `period` 个价格的 SMA 起始；效率比为 `period` 柱净变动除以逐柱绝对变动之和，平滑常数为 `(ER × (2/(fast+1) − 2/(slow+1)) + 2/(slow+1))²`；窗口持平时效率为零 | `KAMA` | 价格窗格 |
| `mcginley`（14） | 以第一个收盘价起始，`MD += (C − MD) / (N × (C/MD)⁴)`；非正价格打断递推，直到下一个正收盘价重新起始 | `McGinley` | 价格窗格 |
| `linear_regression`（20/2） | 窗口内最小二乘直线在当前柱的值；通道宽度为 `deviation` 倍的残差总体标准差（不是价格本身的标准差） | `Curve`、`Upper`、`Lower` | 价格窗格 |
| `choppiness`（14，`period ≥ 2`） | `100 × log10(ΣTR / (最高 − 最低)) / log10(period)`，截断到 0–100；首个真实波幅需要前一收盘价，区间为零时为空缺 | `Choppiness` | 振荡器窗格 |
| `atr_bands`（14/2） | 收盘价 ± `multiplier` × Wilder ATR | `Upper`、`Basis`（收盘价）、`Lower` | 价格窗格 |

校验与持久化规则相同：Klinger 与 KAMA 要求 `fast < slow`，Choppiness 要求 `period ≥ 2`，线性回归的 `deviation` 与 ATR 带的 `multiplier` 必须有限且不小于 0，KST 的八个周期与信号周期都必须大于 0。Chop Zone 是单一 Choppiness 输出上的 38.2/61.8 阈值（低于 38.2 为趋势，高于 61.8 为震荡），不另建区域序列，而是在该输出上挂载与 RSI、Stochastic、CCI、Williams %R 和 Stochastic RSI 相同的引擎持有阈值区域（`SeriesThresholdRegion { lower: 38.2, upper: 61.8 }`）：帧构建把它降为振荡器窗格中的半透明通道矩形与两条点状边界线，不新增图元种类，每个后端与宿主无需接线即可获得；区域由指标种类推导，不写入持久化文档，恢复时随绑定重建。上游只在文档中说明该阈值而不绘制，本仓库按所有者决定 Q-D 绘制。

**空白数据**。这 10 个研究遵循“空白数据行如同不存在”的契约（上游自 `0a71a12` 起对递归类采用同一规则）：

- KST、线性回归、Choppiness 与 Vortex 登记在 `compaction_lookback` 中（回看取各输出预热的最大值；KST 的信号线还要读回信号窗口，因此即使平滑短于滞后、缺口落在滞后区间内而不在两端，压缩后的滞后仍只计入有效行），遇到空白数据时在压缩窗口上求值。
- TSI、KAMA、Klinger、McGinley、ATR 带与 Mass Index 在空白数据行输出 NaN 且不推进状态，此后从最后一个有效样本继续，预热只计入有效样本；它们的步进函数取自上游 `ef97955`。McGinley 只在非正价格处重新起始；Klinger 与 Mass Index 对有限的倒挂柱（最高低于最低）不输出、也不重置。
- KAMA 的状态带有最近 `period` 个有效收盘价的有界双端队列（`KamaState.recent`），Mass Index 的状态带有最近 `sum_period` 个比值的有界双端队列（`MassState.ratios`，由 `mass_index_step` 维护），二者都随稀疏检查点保存（`RecursiveHistory<T: Clone>`，检查点只在 1,024 行边界克隆，`bytes_with` 把队列容量计入运行时字节），因此尾部替换与追加为常数工作量，历史修复从最近的检查点恢复，不再像此前那样每个 Tick 从检查点重放约 1,048 行。
- Klinger 与上游不同（本仓库的有意分歧）：价格有效而成交量为空（NaN）或为负的柱按零成交量计入，不贡献力量，也不重启三条 EMA，与 OBV 及其他成交量研究对缺失成交量的约定一致；上游在这种柱上硬重置。调用处以 `volume.max(0.0)` 实现，步进函数保持上游原文。
- 纯计算函数（`kst`、`tsi`、`mass_index` 等）与运行时遵循同一规则（见上文的全序列函数守卫），以“删去空白数据行后的纯计算函数”为参照验证。

**收敛**。KST、线性回归、Choppiness 与 Vortex 为预热；TSI 为预热加长、短两级 EMA 的衰减行数，信号线再加信号 EMA 的衰减；Mass Index 为预热加两次 EMA 衰减；ATR 带为预热加 Wilder 衰减；KAMA 为预热加上以最慢平滑常数 `(2/(slow+1))²` 衰减到 0.1% 以下所需的行数。Klinger 的累计测量只在趋势反转时重启，McGinley 的平滑取决于价格比，二者都没有行数上界，为 `None`。

**尾部工作量**。KST 每个 Tick 重新计算信号窗口内的 KST 值（默认约 450 次 ROC 求值），线性回归与 Choppiness 各为一个窗口，KAMA 为一个效率窗口，其余递归研究为一步。perf_gate Target M 绑定全部 68 个内置研究。

**参考夹具**。`i1_and_i2_reference_fixture_covers_catalog_outputs`（由上游 `i1_reference_fixture_covers_catalog_outputs` 更名）在 60 行确定性序列上为 I1 与全部 I2 输出固定独立计算的最终值，不调用被测的稠密公式。

**与回归趋势绘图的区别**。线性回归指标与 `regression_trend` 绘图（见[绘图 API](../../api/drawings.md)）使用同一种数学：最小二乘拟合加残差总体标准差。指标是滚动的端点序列，每根柱报告以它结尾的 `period` 柱窗口的拟合值；绘图是在两个锚点之间对一个固定窗口的一次拟合，画出整条拟合线与偏移线。二者各自实现，互不共享状态。

**约定**。TSI、Klinger 与 Mass Index 的 EMA 以及 KAMA 都以前 N 个样本的 SMA 起始，McGinley 以第一个收盘价起始；这些种类都没有 `seed` 参数，`IndicatorConvention::China` 不改变它们（`ponytail:` 延后项）。

## 结构与时段研究

摆动点、市场结构、公允价值缺口、订单块、交易时段高低点、上一周期水平与开盘区间是普通的指标绑定：`aeris_charts_indicators` 提供带 1,024 行检查点的结构扫描器、时段状态与按确认行排序的注释，引擎把注释保存在绑定上（不是输出系列），并像内置运行时一样在源的数据末端停止，经同一个输出写入函数（`store_indicator_output`）只写入变化的行。确认语义、空白数据规则、时段日历与只读注释见[结构与时段研究](../../features/studies.md)。

## 研究发布、订单流呈现与 V3

指标的多输入校验由引擎拥有：VWAP 与 VWAP 带绑定需要一个独立的、存活的标量成交量系列，而缺失成交量时仍保留明确的单位权重回退。按成交额加权的 VWAP 额外需要一个成交量系列和一个独立的、存活的标量成交额系列。金融指标绑定同时也是可见性、移除与 chrome 所有权的单位。一次引擎操作即可显示、隐藏或移除绑定中的每个输出，并且保留的图表级指标 chrome 策略会把名称标签、数值标签与价格线应用到当前及之后的输出上。宿主选择该策略并渲染控件；它们不会遍历输出系列，也不会预测输出数量。引擎为每个新创建的专用指标窗格赋予相同的 0.3 拉伸系数，包括金融振荡指标、外部研究、CVD 和 delta（成交量研究仍以 1.0 的拉伸系数打开其窗格）。放入显式选择的已有窗格的研究会保持该窗格由用户选定的高度；每个后端都渲染共享布局。宿主计算的标量研究通过外部研究事务跨越同一边界。宿主提供稳定的研究/输出标识、代次、语义呈现、流需求元数据、时间戳以及可为空的值。引擎在变更之前先校验完整的发布，并拥有其有界输出注册表、代次栅栏、系列与专用窗格的生命周期、价格格式继承、保留的 chrome、分组可见性以及分组移除。

提供方会话与这些值的计算仍由宿主运行时负责。订单流呈现同样作为一次引擎事务安装与移除。引擎拥有共享的成交流图、足迹图/CVD/delta 系列与窗格、空白主系列上的足迹图呈现契约（显示足迹图的宿主把主系列安装为空白数据，它只提供柱网格与时间轴，足迹图系列拥有自动缩放、最新值标签、价格线与倒计时）、保留的指标 chrome、可选的大单指标（显示足迹图时位于足迹图系列上，否则位于主价格系列上），以及自动 1-2-5 行大小策略。产品宿主提供标的/提供方的代次栅栏、规范的有界成交、柱聚合意图、当前价格元数据以及呈现偏好；它自己不会组装或拆除图表依赖图。金融研究持久化 V3 存储绑定定义（包括显式的种子、直方图与估计器参数，缺省时默认采用 TradingView 的约定）、依赖引用、标量输入、成交量与成交额输入以及输出样式，而行情历史与普通系列数据仍由宿主拥有。成交、报价与深度研究输入仍归宿主行情运行时所有：它提供类型化的流需求以及带代次栅栏的借用视图，而 Charts 只接收有界的标量研究输出发布。Charts 不得保留第二份成交带/订单簿，也不得从已渲染的系列推断提供方流状态。Terminal 桥接层现在把传递性的流需求作为有界输出元数据携带，并且只持久化经过校验的宿主绑定；这样既保持了运行时到图表的边界清晰明确，又允许下游输出呈现保留其类型化输入契约。
