## 唯一的交互所有者

浏览器、worker 与 GPUI 宿主通过同一个引擎输入控制器（`chart_input.rs`）路由所有指针、滚轮与键盘输入。宿主将平台事件转换为 `PointerInput`、`WheelSample` 与 `ChartKey` 值并调用 `ChartEngine::input_*`；控制器拥有完整的交互策略：图表区域解析、按下仲裁（实时测量、交易控件、十字光标操作徽标、时间线标记 token、已激活的绘图工具、绘图拖动、Delta Tooltip、Shift 测量、平移；已激活的工具从交易处接管订单线与持仓线主体，并把标记按钮的按下留给它们）、共享 5 px 阈值（平移以及坐标轴与分隔条拖动通过 `GestureResolver`，绘图与交易拖动通过按下自身的锁存）、坐标轴与分隔条拖动、惯性滑行、点击选择与文本编辑激活、双击重置、键盘绑定、滚轮路由、悬停提升、交易提示框停留截止时间，以及语义化的 `ChartCursor`。以下调用会改变静止指针所停留的对象，控制器在这些调用之后会在静止的指针下重新解析该光标与交易悬停（`refresh_resting_pointer_affordance`）：激活或取消绘图工具，交易快照、更新或移除，已答复或已由宿主状态结算的交易请求，可见交易账户，括号单请求，以及键盘订单调整。因此，在自身调用之后应用 `input_cursor()` 的宿主无需指针运动：GPUI 宿主在 render 中通过适配器的 `cursor_style` 读取光标，因此在这些调用之后重绘（notify）；浏览器在其中任一调用使引擎帧待定时重绘，并在其意图处理函数运行之后以及每次重绘之后呈现光标。移除调用的返回值只说明图表是否曾显示该对象，而不说明是否需要重绘：移除一个图表已经关闭的对象仍会答复其请求。worker 图表没有交易 API，也不应用引擎光标。

到达时主按键已处于抬起状态的移动事件（宿主从未见到的释放）、前一次按下尚未结束时的新按下、Escape、次键点击与 `input_cancel` 会放弃进行中的手势而不提交，与浏览器指针捕获丢失完全一致。放弃不等于撤销，并且每种来源的行为都相同，Escape 也不例外。编辑会回滚：绘图拖动回到起点，订单拖动丢弃其预览且不发出意图，手绘笔画被丢弃。视图手势停在当前位置：平移（连同其手动价格平移）、时间轴或价格轴缩放以及窗格分隔条调整，都保留取消之前已做出的部分变更，仍按住的按键不再移动它们。被拖动退出自动缩放的价格轴保持手动，与完成拖动之后一样；保留下来的分隔条比例会像完成的调整一样随工作区保存。这是已确定的产品规则，与没有手势取消的 Lightweight Charts 一致：Escape 绝不回退视图，交易者通过拖回、双击坐标轴或按 Home 撤回视图变更。`input_pointer_captured()` 报告是否有按下处于打开状态（未释放、未被放弃的鼠标或笔的按下，或触摸控制器仍在跟踪的手指）：在它成立期间，按下拥有指针，宿主把指针在任何位置的移动和释放都交给它（指针捕获），并在窗口失去焦点时用 `input_cancel` 放弃它；指针离开图表不会结束它。宿主可配置的开关位于 `InteractionOptions` 中（参考实现的 `handleScroll`/`handleScale` 系列开关，以及 Aeris 自有的 `price_axis_wheel_zoom`）。

只有宿主才能执行的工作以有界的 `ChartInputEvent` 队列形式到达（上下文菜单、点击与双击通知、文本编辑器打开、已创建的绘图、宿主拥有系列的移除、十字光标离开、Delta Tooltip 范围变更，以及携带其已解析命中序号的时间线标记激活）。双击会先结束其所落入的任何按下操作（测量、交易拖动、平移、价格平移、捕获创建），再应用其重置。浏览器与离屏适配器以及 GPUI 探针会在控制器输入之后排空宿主拥有系列的移除；浏览器还会把点击、双击与十字光标事件转发给订阅者，并为引擎拥有的编辑会话打开 DOM 编辑器。宿主保留事件转换、指针捕获、光标应用、定时器与帧调度、菜单、剪贴板以及产品持久化（对 GPUI 宿主而言，输入与倒计时时钟、唤醒定时器、帧调度、视图 notify、指针捕获，以及窗口失活或焦点移开后结束收不到释放或按键抬起的输入，都由共享适配器拥有，见[后端](../rendering/backends.md#gpui)）；它们绝不重新实现路由、光标优先级或按键绑定。因此，新的交互只需在控制器中添加一次，所有原生宿主即可继承。双击只作用于指针下方的绘图（交易控件或提醒徽标保留其点击），并会打开每个带文本的绘图的编辑器；Enter（当没有正在完成的序列时）与 F2 打开所选绘图的编辑器；键盘绑定遵循 `InteractionOptions`（滚动键需要平移或滚轮滚动，+/- 需要滚轮缩放，Home 仅重新适配时间轴并需要时间轴重置开关，被开关拦截的按键保持未被消费）；滚轮与捏合锚点被限制在 plot 区域内。

[时间线标记带](series.md#时间线标记带)的 token 是该仲裁中的一个引擎控件：按下在十字光标操作徽标之后、活动订单组被停用之前被接管，因此按下 token 绝不会清除活动订单组，也不会到达其下方的绘图工具、绘图拖动或平移仲裁；在同一 token 上原地释放恰好发出一次激活（`ChartInputEvent::TimelineMarkActivated(seq)`，宿主经 `timeline_mark_activation(seq)` 读取已解析的命中；拖动不发出任何事件）；起始于 token 的双击绝不会到达其下方的绘图编辑器；悬停回答 `ChartHover::TimelineMark` 与 pointer 光标。交易关闭控件所用的停留截止时间（`TRADING_TOOLTIP_DWELL_MS`，450 ms）同样为 token 的引擎绘制标题提示框计时，规则与关闭控件相同：token 变化会重启它，同一 token 内的移动让它自然流逝，同一 token 下的交易悬停变化只有在新控件自身需要停留（可操作的关闭控件）时才重启它，离开所有需要停留的控件才清除它；按下只清除尚未到期的 token 停留，释放时若指针仍停在该 token 上则重新计时；已显示的标题提示框在按下期间保留。只有触摸按下才按设备 `HitProfile` 加宽 token 的命中框。

类型化比例尺命令会解析生效的系列、在比例尺范围内传播价格格式（所选格式保留在窗格比例尺上，之后加入的系列同样采用，见[比例尺价格格式](panes-and-scales.md#比例尺价格格式)）、切换系列/坐标轴装饰，并把所有已挂接的系列作为一次操作在价格坐标轴之间移动；宿主不会遍历引擎系列来复现这些事务。已提交的绘图编辑、撤销与重做、价格基准变更以及被接受的同步载荷都会推进 `drawing_revision()`（同步载荷所携带的绘图同步修订号），因此宿主依据该修订号持久化，而无需追踪手势。绘图工作期间（工具已激活、正在创建或正在拖动绘图），Normal 模式的十字光标跟随所处理绘图的生效磁吸（`drawing_work_magnet`，规则见下文[绘图放置](#绘图放置)一节）：Strong 总是吸附，Weak 只在 `DRAWING_WEAK_MAGNET_DISTANCE`（12 px）半径内吸附，从不吸附的拖动部位（多锚点主体、锚定文本、头寸工具的第三个手柄）让十字光标保持原始位置。自由浏览时保留原始光标价格，即使宿主尚未清除修饰键标志；显式配置的 Magnet 与 MagnetOhlc 十字光标模式独立于该绘图交互。

在每个宿主上，引擎输入控制器拥有完整的窗格/时间轴/价格轴/分隔条拖动状态机、分隔条与坐标轴目标解析、分隔线处的十字光标排除，以及滚轮平移/缩放路由。平台适配器负责转换 OS 事件，将 `ChartCursor` 映射为一个平台光标，并调度重绘；它不得重现手势生命周期，也不得保留并行的按下、拖动、悬停或光标状态。

## 事件归一化与运动

宿主向引擎发送输入和数据。引擎返回查询结果和准备好的 `ChartFrame`。浏览器和 GPUI 适配器将原生事件归一化为 CSS 逻辑像素的指针和滚轮样本。浏览器、worker 和 GPUI 的指针与滚轮样本都送入引擎输入控制器。解析器拥有指针成员关系、5 px 曼哈顿距离拖动阈值、显式手势状态、固定的起始捏合质心/距离、累计捏合比例、主触点的延续/终止以及取消；它至多保留两个指针，且不对移动样本做分配。捏合移动只围绕起始质心缩放，并且不能在单指移动或长按之后开始。宿主仍拥有平台捕获、光标应用、事件默认行为策略以及帧/定时器调度。GPUI 在适配器处反转其水平滚轮增量，使 `WheelSample` 在每个宿主上都采用浏览器 deltaX 的平移方向和滚轮向上为正的 y。引擎只一次性地归一化原始滚轮轴：像素增量使用源像素比，DOM 行单位保留参考实现的 32 px 规则，页单位保留 120 px 约定。GPUI 在适配器处转换其原生行单位，使默认的三行一档解析为与浏览器相同的 100 px 一档。

浏览器和离屏滚轮事件通过一次 WASM 操作进入 `ChartEngine::input_wheel`，携带其原始轴、模式、平台像素比、已解析的滚轮选项、修饰键和时间戳；控制器拥有缩放/平移路由、运动取消、悬停和光标刷新。GPUI 通过其适配器向同一控制器输入。归一化也包括指针节奏：浏览器已经把指针运动合并到显示帧，原生宿主在笔刷捕获时也必须这样做——Wayland 按每个 HID 报告投递运动（约 1000 Hz，通常每个事件只有一个轴），而把每个样本都送入 `brush_create_add` 会把这种轴交替的阶梯形记录为笔画节点。因此引擎输入控制器只保留最新捕获的样本；原生宿主在每次 prepaint 调用一次 `flush_coalesced_input`（指针抬起时在提交之前刷新），使笔画节点在每个宿主上都按显示节奏采样拖动轨迹。水平惯性滚动与参考实现的域完全一致：拖动样本是时间比例尺的逻辑 `rightOffset`，而参考实现的 0.2/7 px-per-ms 速度限制和 15 px 最小移动量，都除以拖动开始时捕获的柱间距。

因此所得的滑行与缩放无关，而不是按原始指针像素调校。浏览器和离屏键盘事件通过 WASM 进入引擎控制器；左/右平移由速度主导，而非由目标位置主导：按下键给出一次立即的有界速度冲量，只要按键保持按下，引擎就以固定节奏追加低摩擦的冲量，并且宿主的按键重复会被忽略，除非它改变了所请求的 Ctrl/Shift 速度。抬起键立即取消惯性状态。没有显式按下/抬起阶段的 worker 键事件是一次离散按键。在宿主请求减弱动效时，每个方向键事件应用一次离散步进，且鼠标平移松开后绝不滑行。Ctrl/Shift 与普通方向键保持现有的 10x 强度关系。控制器通过引擎历史暴露绘图撤销和重做；GPUI 在此绑定这些快捷键，而浏览器和离屏适配器现在也通过同一控制器路由这些快捷键。Escape 会排入一个有界的宿主事件，使浏览器十字光标订阅者在引擎清除悬停之后收到其光标离开回调。缩放、滚动、惯性运动、磁吸、选择、绘图/交易预览语义以及回滚都归属于此。

## 触摸、点击与唤醒

浏览器和 worker 的鼠标、笔和触摸样本通过 WASM 进入引擎输入控制器。两个适配器使用相同的触摸捏合成员关系、缩放、取消以及主手指延续。浏览器只保留 DOM 触摸捕获和页面滚动方向仲裁；让位于页面滚动会立即取消控制器的按下。控制器还通过其唤醒截止时间，在静止的窗格触摸 240 ms 时进行调度。在该唤醒时刻，它进入十字光标跟踪，使十字光标在单指移动期间保持锚定而不平移，并应用所配置的下一次轻触或触摸结束退出规则。在该跟踪之外，手指没有悬停：触摸按下、平移、坐标轴拖动，或捏合之后剩下的手指，都不显示十字光标，与参考实现一致；只有拖动交易线或绘图的手指才会显示它，且显示在放下点。浏览器和 worker 宿主调度该引擎截止时间，并在其到达时调用 `input_tick`。对于被消费的滚轮输入，控制器使用滚轮事件的位置来提升悬停并解析光标；浏览器在事件之后应用该光标，即使没有指针运动。宿主提供 CSS 逻辑坐标、指针标识和设备，以及已配置的交互开关；控制器拥有捕获标识、5 px 按下阈值（`CLICK_SLOP_MANHATTAN`，浏览器也读取它用于页面滚动方向仲裁）、点击识别、平移、坐标轴手势、悬停和光标优先级。

外来指针不能移动、释放或取消被捕获的按下。浏览器和 worker 的触摸成员关系与延续遵循该控制器规则。该阈值在每种设备上约束每一种指针对象拖动：绘图的主体、锚点与手柄，订单线，以及 `TP`/`SL` 保护手柄都在按下时打开各自的会话，但在按下从起点移动 5 px（曼哈顿距离）之前不移动任何东西。从未越过阈值的按下是一次点击：它不移动任何东西，不记录撤销步骤或修订，也不发出交易意图。越过阈值的那个样本会让对象立即追上指针（绘图按指针相对按下点的偏移移动，订单移到指针下方的价格），之后的样本精确跟随，退回阈值之内时亦然。本身就是第一个越过阈值样本的释放，是该拖动的最后一个样本。一旦运动已形成拖动，释放就按最后显示的状态提交对象，因此在松开按键之前先松开的磁吸（Ctrl/Cmd）或拉直（Shift）键不会改变任何东西。该约束位于控制器的指针路径中，而不在拖动会话方法中，因此键盘微调和直接的引擎调用仍像以前一样移动对象。

控制器通过原生点击计数或其有界的 500 ms/5 px 历史识别重复按下；触摸双击的两次轻触可以相距 30 px（参考实现的 `DoubleTapManhattanDistance`）。它在静止的第二次松开时提交双击；若有移动则保留该手势，因此选择绘图锚点并立即拖动在每个宿主上都可行。浏览器和 worker 指针适配器把设备、修饰键和已配置的选项位打包进一个无分配的 WASM 参数。控制器按下完成之后，浏览器把引擎交易意图和提醒请求分发给宿主订阅者。窗口修饰键事件即使在图表画布没有键盘焦点时也会到达控制器。引擎拥有交易提示框停留截止时间；浏览器为所暴露的截止时间调度一个定时器，并在其到期时对鼠标、笔和触摸输入调用 `input_tick`。

## 悬停、刷选与键盘焦点

可选的浏览器可刷选 Area 辅助函数会安装一个由引擎拥有的组合，由一个普通 Area 系列及其 Delta Tooltip 构成。它仅通过 WASM 发送显式的样式覆盖；引擎保留所选范围，将其默认刷选样式与被覆盖的刷选样式应用到帧上，并通过共享的输入控制器在 Escape 或双击时清除范围。鼠标与触摸的对比手势（单点触摸为预览，双点触摸提交范围）在控制器内部运行；每次变化会在每次排空时排入一个 `DeltaTooltipChanged` 事件，浏览器将其转换为范围监听器通知。该辅助函数查询活动范围并解除该组合，而不添加宿主输入监听器。GPUI 的输入适配器在每次 prepaint 时把 `App::reduce_motion()` 转发给引擎的动效策略，然后才推进输入动画。同一策略会移除装饰性的最新价脉冲（`last_price_pulse_active()` 与帧中的脉冲）。浏览器随每个指针和按键事件转发 `prefers-reduced-motion`，因此在浏览器中脉冲要到第一次图表输入时才停止；在创建时就传入该偏好是包的后续工作。GPUI 没有四向移动光标，因此其适配器将 `ChartCursor::Move` 映射为张开的手形（在 Windows 上为指向手形；GPUI 在 Windows 上将手形光标绘制为箭头）。悬停仲裁由引擎拥有（`ChartEngine::resolve_pointer_hover`，通过 `input_hover` 读回）：浏览器插件图元是 JS 对象，因此 WASM 将其最佳命中收集为 `HostPrimitiveHit`（系列、z 层、是否提供了光标），引擎按照参考实现的 `hitTestPane` 顺序，将其与绘图、系列和通用系列项进行排序。

控制器决定图元光标能否胜过活动按下、图表工具和内置对象；浏览器仅在控制器选中时才应用回调的 CSS 光标，仅在光标变化时才写入光标，并且仅当 `frame_pending()` 报告存在过期的已准备帧时才在输入后重绘，因此相同的悬停采样不会产生帧工作。成交量分布指标是原生系列图元而不是输出系列，因此控制器自行对其已绘制的行做命中测试（在绘图之后、系列之前）。悬停在某一行上会显示 pointer 光标，并把 `volume_profile:{id}` 报告为悬停对象；点击会选中该分布（同时清除系列选择、绘图选择与通用选择），并在其首行与末行、控制点（POC）以及价值区边界上绘制选择锚点。Escape 取消选中，Delete 将其移除，与指标系列完全一致。浏览器无障碍层暴露的键盘焦点目标（价格坐标轴、时间轴、窗格分隔条、绘图）通过 `input_target_key_down` 并携带 `ChartFocusTarget` 路由。引擎拥有它们的绑定：价格坐标轴的 Home/ArrowUp/ArrowDown、时间轴的 Home/ArrowLeft/ArrowRight、分隔条的 Home/ArrowUp/ArrowDown，以及键盘绘图编辑会话（Enter 打开或提交，方向键微调，Tab 循环切换锚点，Escape 恢复起始状态，Delete 删除）。绘图在水平方向上逐柱移动，因此左右方向键每次微调一根柱（按住 Shift 为十根；旋转矩形的宽度手柄保持连续，每次 1 CSS px），上下方向键每次 1 CSS px（按住 Shift 为 10 px），见[绘图](drawings.md#规范状态与工具目录)。

一次已提交的键盘绘图编辑是一条撤销记录；浏览器只负责播报结果。

## 绘图放置

在图表拥有焦点时，Backspace 与 Delete 移除选择（绘图；否则依次为成交量分布、引擎指标，或通过 `RemoveSeries` 移除的宿主系列），但正在放置绘图时除外：从第一次点击创建锚点式放置的待定绘图起，或在捕获手绘笔画期间，该绘图拥有这两个键（`drawing_placement_under_way`）。每次按键都通过 `drawing_create_pop_anchor` 退回其最近放置的锚点（路径与折线的顶点和固定点数工具的点击都是如此），并保留实时预览。退回到没有任何点的放置仍保持待定并继续拥有这两个键，因此按键自动重复绝不会落到选择上；它的下一次点击会重新放置，并重新绑定窗格。没有任何已放置的点时，它还不在指针处绘制任何东西，因此十字光标会显示出来，用于瞄准那次点击，与第一次点击之前一样。在第一次点击之前，这两个键作用于可见的选择，激活工具不会清除该选择。绘图焦点目标保留其自身的 Delete，因为聚焦它就是选择了该绘图。放置期间的撤销保持不变。

点击放置是每个点击放置类工具的既定产品规则：固定点数工具、多次点击的路径与折线，以及单次点击的多头与空头头寸预设。每个锚点都来自一次点击，放置在按键抬起之处；完成绘图的那次点击提交它（序列在双击或 Enter 时结束；折线放置三个或更多顶点后，点击其第一个顶点也会结束并闭合它，这由引擎的放置控制器判定，见[形状](drawing-families.md#形状)；若该点击是一次双击的第一次点击，控制器会把这对点击记为已用于放置（`SpentClick::Placement`），第二次点击与双击结束序列时一样只结束放置，不会为新折线打开编辑器，也不发出双击通知）。越过共享 5 px 阈值的按下，无论是在运动中越过还是仅在释放时越过，都是一次拖动，不放置任何东西；它既不平移，也不报告点击，工具保持激活。已有第一个锚点时，拖动只移动实时预览，与悬停完全相同；被取消的拖动让放置保持原样，因此取消没有需要回滚的内容。控制器在释放时应用该规则：它只对从未移动过的按下调用 `drawing_tool_activate`。手绘工具（画笔、荧光笔）属于按下拖动类，文本在按下时放置。临时的 Shift 测量在拖动时仍会测量，因为它从不被存储。按下-拖动-释放式创建（MetaTrader 模型）经过考虑但未被采用：参考实现的绘图工具示例（Lightweight Charts 的矩形插件、KLineChart 的分步 overlay）都通过点击放置每个点。越过阈值的抖动点击只需再点一次，而不会提交一个不想要的微小绘图并让一次性工具失效。

磁吸修饰键只由控制器读取：指针样本或修饰键变化中的 Ctrl/Cmd（`control || meta`）以 `DrawingModifiers::magnet` 传给放置与拖动，并且仅在绘图工作期间（工具已激活、正在创建或正在拖动绘图）通过 `set_crosshair_ohlc_magnet` 报告给引擎，作为临时磁吸切换；自由浏览时从不报告。`drawings.rs` 按绘图解析实际生效的磁吸（`effective_drawing_magnet`：绘图自身模式与图表模式取较强者；按住修饰键时，自身为 weak 或 strong 的绘图升为 strong，自身为 off 的绘图翻转图表模式；多锚点主体拖动不吸附），十字光标通过 `drawing_work_magnet` 读取同一结果，因此十字光标与锚点落在同一个已渲染 OHLC 候选值上（`weak` 只在 `DRAWING_WEAK_MAGNET_DISTANCE` 内吸附）。宿主、WASM 适配器与 GPUI 适配器都不参与磁吸接线，每个宿主原样继承该行为。

## 上下文查询与取消

次键点击使用引擎拥有的 Chart Context 查询。它解析图表空间坐标、窗格、时间、逻辑索引、命中的系列，以及该系列精确比例尺上的价格（在空白区域则使用窗格的规范默认比例尺），而不执行主点击的选择或激活。浏览器与原生宿主可以使用该载荷构建菜单、剪贴板操作或订单 UI，但这些副作用仍在引擎之外。

所有交互命中测试都使用引擎的 `HitProfile`。鼠标与触控笔保持精确容差；触摸将语义锚点和可操作的交易控件扩展到有效的 44 CSS 像素目标，而不改变视觉几何。由指针取消/捕获丢失、宿主焦点或可见性丢失、尺寸调整、后端丢失或销毁引起的取消，会在当前位置无惯性地关闭比例尺/滚动会话（平移、缩放或分隔条调整保留其部分变更），并恢复绘图/交易预览而不是提交它们。

## 操作徽标与指针反馈

引擎输入控制器拥有作为按下目标的十字光标操作徽标：悬停其上会解析出指针光标，按下它会阻止其下方的图表平移和选择，在命中区域内未发生移动的释放会发出共享的操作请求。指针取消会丢弃待处理的按下。GPUI 演示在其状态栏中显示该请求的窗格和价格。

可交互的图表对象拥有指针反馈：当任何交易对象或绘图处于悬停、创建或拖动状态时，共享帧会抑制完整的可视十字光标（线条、标记和坐标轴标签）。跟随中的 Shift 点击测量是例外：它通过十字光标读取指针，因此即使在其他对象之上，十字光标也保持可见。引擎保留十字光标位置用于吸附和宿主回调，而每个宿主继续显示该对象的指针、点击、抓取或拖动光标。
