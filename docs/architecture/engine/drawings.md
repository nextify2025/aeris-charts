## 规范状态与工具目录

绘图锚点、种类、样式、窗格关联、稳定的 z-order 与元数据仍是唯一权威的已提交绘图状态（临时的悬停/选择/拖动/编辑提升绝不会改写它）。内置工具语义由一份编译期引擎目录描述：稳定的传输标识与名称标识、放置类别、点数规则、手柄策略、移动轴限制、拉直行为、语义边界范围、默认值以及平台编辑请求。趋势线标签相对于实际线段而非其包围盒解析其 3×3 的左/中/右与上/中/下位置；行内居中标签会围绕其度量出的文本范围拆分共享描边，因此没有后端会穿过字形绘制。该目录包含作为单击预设工具的 Long Position 与 Short Position，其已提交的语义点为入场、目标/宽度与止损。目标与止损被规范化到入场价的相对两侧，止损共用起点边，编辑使用四个专用控件（目标、入场/起点、宽度、止损），而不是通用锚点行为。它们的一键预设以 2:1 的回报/风险比非对称地展开，包含仅填充的入场→目标盈利区与入场→止损亏损区、一条细的中性灰色中心入场线、仅在仓位被选中时显示的目标/止损统计标签与居中的 P&L/Qty 和风险/回报摘要，以及填充为中性/绿色/红色、位于所属比例尺 Y 轴上的价格标签。

仓位运行进度是一个派生的三态模型，以仓位在水平方向上的存续期为界。待成交仓位在放置后的第一根 K 线触及或穿越入场价之前不产生进度；该 K 线成为进度起点，位于精确的入场价格。在已成交且活动期间，终点为框内最新 K 线的收盘价/当前值，因此活动的回报/风险一侧跟随当前仓位状态，而不是历史或当前的影线极值。成交后第一根触及目标或止损的 K 线完成该运行：先触目标则冻结在精确的目标价，先触止损则冻结在精确的止损价；同一根 K 线同时触及目标与止损时，保守地按先触止损处理，因为 OHLC 无法确定 K 线内部的先后顺序。较强的不透明度只覆盖从首次成交入场到当前/终点价格所经过的 x/y 矩形，绝不覆盖整个 TP/SL 区域或未触及的空白区域，并且叠加层与连接线都不会超出仓位矩形。回报与风险使用同一个显式的进度强调不透明度，强于未触及的基础区域不透明度，因此 SL 运行与 TP 运行得到完全相同的强调，而不依赖细微的重复 alpha 混合。连接线仍为虚线的中性灰色。LOD 极值摘要加前缀二分查找，使长期存续仓位的入场穿越与首次边界触及的发现保持有界；跨越入场价的 OHLC 跳空被确定性地视为一次穿越，并绘制在语义入场价位上，因为没有可用的精确 K 线内部路径。进度叠加层与窗格 chrome 一起重建（系列更新本就使 chrome 失效，因此每个 tick 无需重建所有绘图），但帧组装把每个仓位的进度图元放进其所属绘图的分段（`position_progress_parts`，分段修订号取两个缓存修订号中的较大者），因此进度保持该仓位的 z-order，不会盖住堆叠在其上方的绘图，保留绘图分段的后端也能看到 tick 更新（上游 `78475b8`）。

运行叠加层经由窗格 chrome 转换，因此系列更新不会重建保留的绘图几何；所有统计标签都在它之后发出，因此虚线趋势绝不会盖在其文字上方。该目录不是运行时插件注册表；添加内置工具是扩展这份确定性的、由引擎拥有的定义，而不是教每个宿主或渲染器如何处理该工具的行为。每个图表本地的 `DrawingController` 拥有已启用的工具/模板，以及待定的锚点放置、已捕获的手绘状态和临时的 Shift 点击测量。引擎输入控制器通过通用的按下/移动/释放/激活/完成/取消操作驱动它，这些操作的含义由各放置类别决定（手绘捕获按下拖动，文本在按下时放置，其他所有类别通过点击放置，见[绘图放置](input.md#绘图放置)）。浏览器、worker 与 GPUI 宿主只转发指针与按键输入，仅保留平台职责，例如指针捕获、事件合并、编辑器界面与重绘调度；宿主不会根据具体的绘图种类分支来决定创建行为。

时间吸附不是逐工具的标志：除固定在屏幕位置上的锚定文本外，每个目录工具在创建、锚点拖动、矩形边界手柄与派生手柄拖动以及主体移动中，都把 x 解析到十字光标的时间槽（创建与矩形边界手柄经 `ChartEngine::grid_snap_point`，锚点拖动与主体移动经 `drag_slot_steps`，派生手柄的指针拖动直接取目标位置下的 `snapped_crosshair_index`），因此绘图在水平方向上逐柱移动。磁吸实际选中某根柱时以该柱为准；磁吸已开启却没有选中柱（强磁吸位于空白处，或弱磁吸离每个价格都太远）时，锚点仍落在槽位上。Shift 拉直在槽位吸附之后进行，因此其精确角度或正方形得以保持。手绘捕获（画笔、荧光笔）不吸附；旋转矩形的宽度手柄表示一个垂直距离，保持连续。主体移动对每个锚点施加同一个整柱位移，带小数逻辑位置的锚点（拉直后的锚点、旋转矩形的宽度）保留其小数部分；锚定文本按自身的屏幕 px 路径移动，不经过这个整柱位移。指针拖动的整柱步数从被抓取的手柄自身的像素位置起算（`drag_slot_steps`），而不是从其语义锚点起算，因此投影到描边上、语义锚点却位于屏幕外的手柄（例如通道的第三个锚点）不会被十字光标的可见范围钳制拉到窗格边缘。`snap_time_to_data` 的数据钳制检查锚点或派生手柄目标在步进之后的最终槽位：投影手柄可能在锚点自身像素尚未跨柱时就跨过一个槽位，因此只检查换算点会让步进把锚点带出数据范围。键盘微调在水平方向按整柱步进：`nudge_selected_drawing` 把水平位移取整为整数个柱间距、至少一个，输入控制器的方向键每次一根柱（按住 Shift 为十根）；其步数在逻辑空间中计算，因此经手柄循环选中的屏幕外手柄也恰好移动其柱数。旋转矩形的宽度手柄保持连续：微移不取整其水平位移，方向键每次移动 1 CSS px（按住 Shift 为 10 px）。派生手柄的键盘目标是手柄自身逻辑位置加整柱步数且不取整，奇数宽度叉形线底边的中点因此保留半柱，由该族自身把 B、C 按整柱移动。价格吸附同样不是逐工具的标志（上游 `12035e2` 删除了 `price_tick_snap`）：除锚定文本外，每个目录工具在创建、锚点拖动、矩形边界手柄与派生手柄拖动以及主体移动中，都把价格解析到品种的 `tick_size`（若无则回退到所绑定比例尺的 `min_move`，带 `PriceTickLadder` 的比例尺取其价位带的 tick），因此绘图在竖直方向上逐 tick 移动。磁吸实际选中的 OHLC 价格保持精确（`magnet_chose`），手绘捕获及其主体移动不吸附，以保持描边形状；主体移动只在竖直位移（经 Shift 与移动轴约束之后）不为零时吸附，单锚点主体被磁吸选中某根柱时不吸附。只能水平移动的种类（垂直线、固定范围与锚定成交量分布、锚定 VWAP 与回归趋势）在锚点与派生手柄拖动中不吸附价格：其竖直位移被约束为零，存储的价格因此保持不变，只按时间的拖动绝不改写它（决策 C1）。键盘的竖直微调至少移动一个 tick（沿按键方向，`keyboard_position_price` 按价位带阶梯计数）：锚点、主体与仓位控件之外，矩形边界手柄与派生手柄同样如此，叉形线底边把 B、C 按整数个 tick 移动；旋转矩形的宽度手柄与图标外框的角保持连续。文档在加载时从不吸附。除 12 px 的荧光笔外，每个目录工具的默认线宽为 1 px；已存储的线宽不变。

## 派生运行时与几何

图表本地的派生运行时将既有的单调 `DrawingId` 值映射到保守的逻辑/价格边界、以坐标为键的媒体空间锚点几何，以及窗格本地按 z-order 排序的候选列表。候选查询先在语义空间中排除绘图，再测试缓存的保守屏幕边界；只有视口或指针候选才会重建坐标几何，并进入规范图元发出或精确命中测试。工具锚点在进行本体命中测试或 `Prim` 发出之前，先解析为一套与后端无关的绘图几何词汇，因此交互本体与渲染本体共享相同的线段/射线/整线/矩形/折线几何与端点装饰（核心工具与 AerisTerminal 的 B8 目录通过 `drawings/geometry.rs`；七个自有线工具与三个范围工具通过[绘图族](drawing-families.md#部件词汇与转换)中所述的共享部件词汇）。只有帧构建会将该已解析几何转换为共享渲染 IR；Canvas2D、WebGPU、GPUI 与原生/无头执行器绝不会接收绘图种类，也就无法分叉工具语义。核心的虚线或点线描边（趋势线、路径、曲线画笔、形状外框）通过 `push_styled_stroke`（`aeris_charts_render::line`，与系列线的 `push_line_stroke` 并列）以实线虚线段的形式到达执行器：虚线段先按其线型展开，再裁剪到按描边延伸范围外扩后的窗格并拆分，因此每个执行器都依据相同的虚线段绘制出相同的虚线，延伸到窗格之外很远的线只会拆分其可见延伸部分；实线描边仍为一条折线。

通用系列线以同样的方式转换其虚线。全幅水平线、全高垂直线与半无限水平射线保留显式的无界维度，而不是伪造的有限范围。多次点击的路径存储两个至 100,000 个顶点，发出一条带开放式终端人字箭头的直折线，暴露每个顶点以供编辑，将两个箭头翼视为本体移动目标，并且仅在双击或 Enter 结束它时才提交一条历史命令；Backspace 或 Delete 移除最近放置的顶点（控制器的[放置按键规则](input.md#绘图放置)），Escape 丢弃待定路径。折线以同样的方式放置；放置三个或更多顶点后，点击其第一个顶点即以闭合形式（`tool_options.shape.closed`）提交它（见[形状](drawing-families.md#形状)）。画笔仍属于按下拖动的手绘放置类别：其边界在语义变更时计算一次，并为曲线插值留出填充，在活动捕获期间保持保守的无界，直到指针抬起时做一次精确重建。捕获按距离对指针采样进行抽稀，样本被拒绝时帧保持不变，因此快速输入仅按每个被接受的点使绘图层失效。运行时边界、已解析几何、控制器状态、计数器与索引条目绝不序列化。

选中手柄由 `drawings/handles.rs` 的 `drawing_handle_set` 唯一拥有：手柄的绘制、放置预览、`selected_handle_hit`、键盘手柄循环与拖动起点都读取同一个集合，因此手柄绘制在哪里就能在哪里被抓取。对只参数化形状、自身不在描边上的锚点，上游的 `anchor_handle_points`（`drawings/geometry.rs`）在该集合内作为投影步骤（`kinds::upstream_derived_handles` 的第一步）把手柄放到它所控制的描边上：回归趋势线的锚点位于未延伸的拟合线两端，平行、平顶与平底通道的第三个锚点以及斐波那契通道的第三个锚点位于第二条线（斐波那契通道为 1 档）上、两个基线锚点中间的 x 处（基线竖直时取第二条线的中点），旋转矩形的深度点位于远侧边的中点。只有这六个种类会为此解析几何，其他种类的手柄集合开销不变。通用锚点拖动把指针位移施加到语义锚点上，因此投影的手柄随其描边移动。叉形线的叉柄中点、固定江恩方形的对角、旋转矩形的近侧宽度手柄与自有线外观中锚点重合的路标的杆顶仍是派生的 `Handle(k)`（见[绘图族](drawing-families.md#目录与共享钩子)）。手柄模式按绘图解析（`drawing_handle_mode`）：自有线外观的便签、评论与价格便签没有手柄（保持其焦点框），自有线外观的路标使用两个锚点加派生的杆顶，其余绘图取目录规格的模式。集合同样拥有上游 `12035e2` 的两种模式：`IconBox`（图标与箭头标记）在任何族钩子之前给出图标外框的四个圆形角手柄（`Anchor(0..4)`，光标为 `nwse-resize`/`nesw-resize`），拖动或方向键调整 `icon_size`（8..256 CSS px，键盘按 CSS px 连续调整，不按柱或 tick 取整），撤销、取消与键盘编辑的 Escape 都恢复原尺寸；`OneAnchor { index, square }` 只为一个锚点给出手柄（无外观块路标的顶部为方形手柄）。每个手柄经同一个 `push_handle` 绘制（上游 `12035e2`/`78475b8`）：一个对齐到设备像素的 12 CSS px `RoundRect`，自带填充与内侧边框，圆形或圆角 2 px 的方形，边框 1.5 CSS px 向下取整到整设备像素、至少 1 个，因此每个工具、每一侧与每个后端的手柄环宽度相同；`HandleShape` 只有 `Round` 与 `Square`。

不位于主体上的定义锚点由构造引导线与主体相连，引导线随主体一起解析（`ResolvedDrawingGeometry::guides`）：斐波那契扩展与趋势时间穿过三个锚点的两段虚线趋势腿，以及叉形线族的实线叉柄底边（第二与第三个锚点 B、C 之间，内部叉形线为从 B 到 2C − B），中线起点不在第一个锚点上的变体另有一条从第一个锚点到中线起点的虚线腿。帧把每段引导线作为单独的一段经 `push_segment` 转换，位于区带填充之下，因此每段虚线都从自己的起点开始绘制；命中测试把引导线视为主体的一部分。带存储的 `tool_options.fibonacci` 块的斐波那契扩展与趋势时间既不绘制也不命中引导线，而保留自有线的趋势线（`kinds::fibonacci::draws_guides`，见[绘图族](drawing-families.md#斐波那契)）。

创建过程预览每个放置阶段。已知全部锚点（已放置的锚点加指针）后，待定绘图经完整的已解析几何绘制；在此之前，多锚点工具把已放置的锚点与指针连成一条以绘图描边绘制、裁剪到窗格的引导折线（柱形态改为把前两个锚点围成的源窗口显示为虚线外框，与它被选中时显示的外框相同），并在已放置的锚点上显示手柄，因此形状逐次点击地建立起来。

## 目录工具几何与语义

线条目录还包括有向射线、延长线、信息线与角度线、十字线以及箭头线。射线边界保留自第一个锚点出发的方向，用于视口剔除；共享解析器把射线与延长线投影到窗格边缘，射线另按 `extend_left` 穿过第一个锚点向后投影，信息线、角度线与箭头线按 `extend_*` 投影（竖直线段也延伸到窗格的上下边缘）。十字线把一个锚点解析为完整的水平臂与垂直臂。箭头端帽以及信息线或角度线的装饰在有序帧中发出，因此后端不解释这些种类。不带存储的 `tool_options.line` 块时，角度线从第一个锚点绘制一条 60 CSS px 的点线水平参考线、一条从参考线扫到线段的点线圆弧，以及参考线末端旁带符号的角度（逆时针为正，文本取自共享的度量格式化器）；信息线绘制一张统计卡片，其样式取包的工具提示面板按绘制背景选出的浅色或深色 token（`--surface` 填充、1 px `--border` 边框、默认圆角、`--text-primary` 数值、弱化的图标、12/16 px 字体），位于线段中点旁线条让出的一侧并钳制在窗格内，每行以帧绘制的图标开头，依次列出可见的价格变化（百分比）与 tick 数、柱数（经过时间）与像素距离，以及角度。卡片的文本同样经共享的度量格式化器（带符号），标签自身的 `text` 取代其度量值，缺失的百分比或 tick 数显示为“—”，没有时间数据的经过时间被省略，可见的 `date_time_range` 标签代替隐藏的 `duration`。带该块的绘图保留自有线的统计框与角度线外观（见[绘图族](drawing-families.md#线条)）。平行通道、平顶/平底通道与不相交通道只解析一次其边界，供共享的命中测试以及填充与描边发出使用；其定义锚点仍是可编辑、被持久化的几何。回归趋势由两个锚点选出一个逻辑窗口，对其源系列中所选源值（`tool_options.channel.source`，默认收盘价）的有限值做拟合，并推导出残差标准差带，每一侧的偏移按 `regression_band` 解析（见[绘图族](drawing-families.md#通道)）；源、窗口与记忆化的拟合见[绘图族](drawing-families.md#系列数据读取方)。其源标识、偏差设置与派生的媒体几何由引擎拥有；其源系列的变化会使保留的绘图帧失效，源代次则使绘图几何缓存失效。

斐波那契回撤由两个锚点解析出七个默认水平层级；扩展从第三个锚点投影一段价格与时间波段，通道对一条倾斜基线做偏移，时间区与趋势时间依据度量出的间隔投影垂直层级，速度扇形从共享枢轴投影倾斜层级，速度弧与圆围绕第二个锚点采样同心层级，螺旋线从第一个锚点采样有界的对数圈，楔形则在由两个锚点定义的两条侧边射线之间采样同心弧。每个被持久化的层级控制可见性、颜色、描边样式、可选的到前一层级的填充以及一个标签。存储的 `tool_options.fibonacci` 块在这些分支之上叠加趋势线、扇形网格、完整的速度弧圆、垂直标签对齐与环形工具的精确圆环，没有层级的螺旋线绘制黄金螺旋；层级标签与选中时的层级区带同层级线一样是主体命中目标（见[绘图族](drawing-families.md#斐波那契)）。投影后的逻辑边界使未来的时间层级保留在视口候选中，而无需把每个绘图都扩展到整个窗格。Andrews、Schiff、修正 Schiff 与内部叉形线由三个锚点推导出各不相同的中线起点与平行的层级叉齿；叉形扇（`pitchfan`）对穿过外侧锚点的射线使用相同的层级与帧契约。

江恩框把两个锚点解析为带有样式化层级的价格与时间网格。江恩方形在该网格上增加可各自设置样式且有界的角度射线与四分之一弧；固定江恩方形由锚点解析出一个媒体空间中的正方形框。这三类层级各自拥有独立的 schema、补丁、持久化与层级间填充控件。江恩扇形从其枢轴向窗格边缘投影九条成比例的角度射线。帧构建与精确命中测试使用同一份共享几何。

斐波那契、叉形线与江恩层级工具通过其类型化绘图 schema 与持久化选项暴露反转、价格/数值/百分比标签的可见性以及标签对齐。回撤、扩展与通道层级可按需对正价格做几何插值；其帧路径与命中路径使用同一结果。反转会镜像归一化后的层级，把时间区层级移到其起点的另一侧，并对正的江恩扇形比率取倒数。绘图边界包含可见的投影层级，因此即使某个层级的锚点位于视口之外，该层级也能进入视口。仓位绘图保留其专用的目标、入场与止损统计，而不暴露这些通用的层级控件。

投影用两个锚点表示顶点与未来目标；目标的时间与价格共同设定水平方向的时间跨度与投影高度。引擎把其填充扇区解析为一个共享三角形，供渲染与命中测试使用。

预测用两个锚点表示入场与未来目标。引擎检查其源的最高价或最低价，直至目标逻辑槽位为止（哪些柱计入见[绘图族](drawing-families.md#系列数据读取方)）；帧为已到达的目标、已过期的时间跨度或待定的预测标注标签，并在该标签上方一行显示目标柱的时间。该状态由当前图表数据推导，不会脱离可编辑锚点而单独持久化。

柱形态在放置提交时，从源窗口把至多 512 行有限的 OHLC 数据捕获到绘图中。第三个锚点移动该冻结副本，而无需再次读取源。水平与垂直镜像，以及柱、开收盘棒（`oc_bars`）或所选价格连线模式，都是由 schema 支持的样式选项。该有界快照随绘图持久化，并经剪贴板与跨单元格同步负载携带，因此接收方图表无需持有源数据。帧构建与精确命中测试通过活动价格比例尺投影同一份快照，并针对每种模式测试相同的描边。移动某个源窗口锚点会在编辑提交时重新捕获快照；移动目标锚点则保持快照不变。

周期线与时间周期由两个锚点推导出重复的垂直标记，把可见标记限制为 256 个，并让帧输出与命中测试共用同一生成过程。正弦线把经视口裁剪的四分之一周期区间采样为至多 512 段；命中测试探测的正是这些线段。谐波形态与图表形态以及艾略特波浪是有序、可编辑的锚点路径，顶点标签由引擎拥有，帧、命中测试与剔除余量共用同一放置函数（`patterns_elliott_cycles::vertex_labels`），形态在折线分支之上叠加的比率连线、填充、颈线与三角形两边经共享部件转换（见[形态与艾略特波浪](drawing-families.md#形态与艾略特波浪)）。艾略特级别（`subminuette` 至 `grand_supercycle`，外加 `submillennium`、`millennium` 与 `supermillennium` 三个级别）随绘图补丁校验、在其 schema 中暴露，并随绘图持久化，按其 Frost–Prechter 记法标注各浪；带圆圈的级别把圆圈作为 1 CSS px 的展平折线描边发出，每个执行器都从帧中绘制由此得到的文本与圆圈。折线与荧光笔复用可变点数的放置类别；荧光笔的 alpha、宽度与只填充一次的 tube 在共享帧中转换。旋转矩形、椭圆、圆、三角形、弧以及二次或三次曲线同样会先解析为共享的媒体空间几何，再进行帧转换或精确命中测试。曲线经过其锚点（上游的契约，`interpolating_curve`）：二次曲线经过中间的锚点，三次曲线经过两个内部锚点，因此每个锚点都在描边上，是普通的锚点手柄；贝塞尔控制点由锚点推导，`DrawingBounds::for_drawing` 把推导出的控制点计入曲线与双曲线的语义边界（价格同时取线性组合与对数空间组合两个候选，因此在每种比例尺模式下曲线都位于边界内），锚点滚出窗格而曲线的凸出部分仍可见时，曲线照常绘制与命中。椭圆保留外接框的八个手柄（决策 S3）。椭圆、圆、弧、曲线与双曲线按感知裁剪的方式展平（`geometry.rs` 中的 `ellipse_outline`、`ArcGeometry::flatten` 与 `CurveGeometry::flatten`，基于 `aeris_charts_render::shape` 的 `EllipseArc::append_clipped_points`、`flatten_quadratic` 与 `flatten_cubic`）：帧在位图 px 中、命中测试在媒体 px 中，以按描边半宽加 16 CSS px 外扩后的窗格为裁剪范围，把曲线展平为与真实曲线相差不超过 0.1 px（`CURVE_TOLERANCE`）的弦，裁剪范围之外的片段只保留一条弦，因此放大到极大半径时屏幕上的曲线仍保持圆滑，而每条曲线至多 `MAX_FLATTEN_POINTS` + 1 个点；绘制与命中测试使用同一展平规则，因此二者不会漂移。描边经 `push_styled_stroke` 转换（虚线或点线外框以实线虚线段到达执行器），点全部落在裁剪范围之外的弧或曲线、外接框与裁剪范围不相交的椭圆或圆不绘制任何内容；椭圆的填充是展平外框的 `shape::convex_ribbon`（`BandFill`），圆的填充仍是精确的 `Prim::Circle`，椭圆内部与圆的命中测试仍为解析判定。`EllipseArc::append_clipped_points` 用椭圆真实的（旋转后的）半宽与半高判断它是否整个位于裁剪范围内，因此完整可见的椭圆取均匀的弦，填充边缘复用外框的顶点。上游转换在自有线展平之外仍绘制的曲线按 `arc_segments` 均匀细分（每段与真实曲线相差不超过 `CURVE_TOLERANCE`，每条曲线 8 至 2,048 段）：不带存储的 `tool_options.fibonacci` 块的斐波那契速度弧、圆与楔形的圆环、江恩方形的四分之一弧，以及角度线的圆弧。

锚定文本存储取自其放置点击的归一化窗格坐标，因此时间与价格比例尺的变化不会移动它；拖动、撤销、坐标补丁、命中测试与持久化都使用同一个屏幕位置。便签、评论、标注框、价格便签与路标是上游 `12035e2` 的框式标注：一个引擎布局 `ChartEngine::annotation_layout`（`drawings/annotations.rs`）解析其文本框、文本行与连接线，帧构建、精确命中测试、剔除余量、绘制的插入符与编辑器布局都读取它，因此绘制的框、抓取区域与插入符总是重合。便签的框悬挂在第二个锚点下，引线连到第一个锚点（图钉）；评论是锚点上的对话气泡；标注框是一个闭合形状（不透明的着色框加尾部，一条轮廓），尾部尖端在第一个锚点上；价格便签是第一个锚点上方的价格标签加一条连到第二个锚点的线，显示其文本或格式化的价格，放置时不打开编辑器；路标单击放置，文本框位于所点柱上方 96 CSS px，由竖直的杆相连，顶部是方形手柄。未设置的框颜色取绘制主题的 token（便签、路标）或绘图颜色（评论与价格便签的填充、标注框的不透明着色与边框），文本取与填充对比的墨色，空框在输入时显示“Add text”占位文本。便签、评论、标注框、价格便签与锚定文本的文本按 `\n` 堆叠为多行（决策 R9，`DrawingKind::multiline_kind`），便签与路标向下生长，评论、标注框与价格便签向上生长；无外观块的路标保持单行。只有一个锚点的旧便签与价格便签仍可加载，其框位于该锚点上，没有连接线。自有线外观由 `kinds::projection_annotations::fork_form` 一个谓词决定：存储了 `tool_options.projection_annotation` 块、种类属于自有线外观种类，且便签与价格便签恰好只有一个锚点；`annotation_layout` 对自有线外观返回 `None`，因此帧、命中、插入符、剔除与编辑器路径不会彼此偏离。不带存储的 `tool_options.projection_annotation` 块时，价格标签发出并命中一个位于锚点右上方的圆角气泡，气泡的尾部尖端落在锚点上，价格文本由引擎格式化，除非被覆盖；帧布局与命中测试共用 `price_label_layout`，其尺寸取自 `kinds::projection_annotations::price_label_bubble`，内联编辑器、插入符与文本命中也位于气泡的文本行上（`price_label_text_start`），剔除余量计入气泡高出锚点的部分。带该块的价格标签保留自有线的对话气泡（见[绘图族](drawing-families.md#投影与标注)）。方向箭头标记与图标戳是图标种类：箭头标记绘制一个实心箭头，尖端落在锚点上；旗标在引擎中解析一个细长的标记几何，包括其命中区域与视口边距。图标戳与箭头标记存储一个显示尺寸 `icon_size`（8..256 CSS px），选中时由四个角手柄调整（见上文 `IconBox`），命中区域是图标外框。图标戳另存储一个有界的名称；图表本地的 RGBA8 注册表至多保存 32 张、每张至多 96×96 像素的图像。持久化保留名称，而宿主在载入后重新注册图像字节。内置的 59 个实心图标（Phosphor 2.1.1 fill，MIT）在引擎中按设备尺寸光栅化（`drawings/icons.rs`），与已注册的图像一样以图像图元发出，GPUI、WebGPU、Canvas2D 与原生执行器按顺序绘制它；`builtin_drawing_icons()` 把同一份 SVG 交给宿主的图标选择器。名称依次解析为：已注册的图像、内置实心图标（已保存的图标戳也是如此）、内置图标中没有的四个自有线字形名称（`check`、`cross`、`triangle_up`、`triangle_down`）的自有线矢量字形，否则绘制一个着色的占位矩形（见[绘图族](drawing-families.md#锚定文本与图标戳)）。GPUI 与 Canvas2D 各自保留至多 64 个已解码的光栅资源，足以覆盖所有图表本地的图标戳以及其他图表图像，而不会在稳态下发生图标戳的换入换出。

## 时间锚点重新定基

当历史插入、移除、系列替换或保留裁剪改变了合并后的逻辑索引时，引擎会通过数据层的公共时间戳映射，对每一个绘图语义的逻辑快照做重新定基：已提交的锚点、待定的创建锚点与预览、活动的画笔点、活动拖动的起始与当前快照，以及两个绘图历史栈。非时间足迹图的重建使用柱序列的全分辨率开/收盘微秒标识映射，而不是行键或截断的秒，包括位于柱之间的小数锚点。公共时间戳精确映射，小数位置在它们之间插值。核心映射还会报告其公共范围、它是否为纯索引平移，以及构建它所依据的旧合并并集。平移（同周期前插、保留裁剪或窗口移位）在公共范围之外保持斜率为一的柱数外推，因此在保留裁剪持续流入时，现有的绘图绝不会跨越交易时段间隙跳动；唯一的例外是前插的历史，其中位于旧数据左侧的锚点会在新柱上解析其外推时间，因此周期切换时放在短历史之前的锚点，在宿主分页载入更多数据时会保持其所处时刻。否则（周期切换，或没有任何公共时间戳的替换），每个位于精确范围之外的锚点会将其在旧坐标轴上的时间解析到新坐标轴上（`drawings/time_anchor.rs`）。

超出持久化取值范围的派生时间与逻辑位置会被报告为无法放置，而已与其占位值一致的待定时间会使该逻辑值保持逐位精确，因此导出与导入的往返是确定性的。在普通时间轴上，锚点的时间标识是派生的而非存储的：逻辑位置 `i` 位于合并时间 `i`，小数位置在相邻柱时间之间插值，超出数据的位置按主导的柱周期外推（取最近 16 个间距中出现最频繁者，因此交易时段与周末间隙绝不会成为步长）。只有无法放置的锚点才会在其 `Drawing` 快照上保留显式的待定时间：先清空再设置会暂存每个已提交锚点与历史锚点的时间（并取消进行中的创建与拖动状态），而在数据存在之前由 API、恢复的文档或同步/剪贴板负载提供的时间锚点，会保持待定，直到下一次时间点变更将其解析。一个有界标志位在稳态下跳过该遍历，非时间柱序列的行键绝不会被读作时间。临时映射把其公共时间戳断点压缩为斜率变化点，并且仅为 `sync_time_points` 中的那一次同步携带移出的旧合并并集；两者都在那里被丢弃，因此不会有第二条合并时间线存活到同步边界之外。

像素拖动/画笔基线会为保持输入连续性而立即刷新，并在下一帧完成布局与自动缩放后再刷新一次。该维护性变更不会创建绘图历史命令。非时间绘图会在其逻辑/价格锚点之外持久化一个可选的、有界的锚点时间附带数据（开/收盘微秒）；旧版文档省略它并保留其既有行为，而恢复出的附带数据会在宿主安装匹配序列时解析。普通时间图表会将每个锚点的时间内联持久化（`{logical, price, time}`），并且该时间在导入时具有权威性：它会立即依据已加载的数据解析，或保持待定直到宿主安装数据，因此恢复到发生偏移的历史窗口、另一个周期或网格工作区（在数据之前导入）时，都会落在已保存的时刻上。

## 历史与价格基准

每个图表还拥有一份有界的、仅存在于运行时的绘图历史，记录最近 100 个已提交的语义创建、删除、锚点、样式与清除操作。指针移动采样会改变活动拖动快照而不增加命令；指针抬起时记录一次从起点到终点的更新。撤销/重做会先取消活动的拖动，仅重建受影响的绘图运行时状态；新的变更会清除重做分支；持久化绝不包含任何一个历史栈。宿主的批量锚点改写会记录一条 `BatchUpdate` 命令。每个已提交的历史步骤（API 变更、交互式放置或手绘笔画、确实改变了内容的拖动或已提交的键盘编辑、文本编辑提交）都会使图表的绘图同步修订号递增一次（可通过 `drawing_revision()` 读取），撤销、重做与价格基准变更也是如此；结束于起点位置的拖动既不记录任何内容，也不递增修订号。按住 Ctrl/⌘ 在未锁定绘图的主体上按下并拖动会复制它（上游 `78475b8`）：副本克隆源绘图（包括 `tool_options`，因此复制的自有线文档保留其外观）并随指针移动，源绘图不动；释放时提交为一条 `Create` 命令（修订号递增一次）并报告 `DrawingCreated`，而未越过点击容差的释放与指针取消会丢弃副本、不记录任何内容，并改为选中源绘图（与普通单击该主体的选择相同）。锚点、手柄、创建与 Shift 测量的按下保持 Ctrl 为磁吸；拖动副本时按住的 Ctrl/⌘ 是复制键而非磁吸修饰键（`drawing_drag_to` 去掉它，输入控制器也不把它报告给十字光标），副本与十字光标只按副本继承的磁吸模式吸附。移除绘图的每条路径（包括撤销一次创建）同时把它从多选集合中删除。价格基准重新缩放（对锚点时间区段施加乘性因子，非时间柱按其开盘时间确定所属时间，Long/Short Position 的价位按入场所在区段处理；只重新缩放锚点价格，不涉及任何工具选项）与时间重新定基一样，属于数据基准变更：它适用于已锁定的绘图，以新基准重写两个历史栈以及进行中的创建/拖动状态，不记录命令，并且当任何被重新缩放的价格会超出其有效范围时整体被拒绝。图表级的价格基准标签是由持久化与同步/剪贴板负载携带的元数据。

## 类型化契约与模板

B2 以带版本的类型化绘图契约扩展了该所有权边界。`drawing_contract.rs` 定义了有界的属性描述符、周期可见性、线端帽、磁吸模式、标签、层级、模板、剪贴板负载（携带锚点时间与价格基准标签，其界限与持久化的绘图文档一致：至多 `MAX_DRAWING_OBJECTS` 个绘图、`MAX_DRAWING_CLIPBOARD_POINTS` 个锚点与 `MAX_DRAWING_CLIPBOARD_BYTES` 字节，字节界限在粘贴解析之前检查；克隆从现有的实时绘图暂存，因此图表持有的任何绘图都可以被克隆），以及带修订号的同步负载。磁吸会从绘图自身模式与图表持久模式中取较强者，解析出一个有效模式；按住 Ctrl/Cmd 时，自身磁吸为 weak 或 strong 的绘图按 strong 吸附，自身磁吸为 off 的绘图则临时翻转图表模式；弱磁吸仅在固定的垂直 CSS 像素距离内生效，键盘微调从获得焦点的手柄自身位置开始，水平方向按整柱步进、竖直方向至少移动一个 tick，并且绝不磁吸（仓位的价位与宽度仍落在仓位工具部分所述的 tick 与槽位网格上）。实时的 `Drawing` 仍是唯一的事实来源；其通用快照与带判别标签的种类选项投影都是计算出的视图，因此属性面板无法创建第二套状态模型。

补丁会在安装之前，在克隆体上校验所有有界的契约字段，并为每次语义变更记录一个撤销条目。共享的已解析几何路径会应用线段延伸，并同时被帧发出与命中测试使用。隐藏或不符合周期可见性的绘图仍保留在持久化与对象树中，但被排除在渲染与命中测试之外；锁定的绘图仍可选择，但不能编辑。选择、克隆/复制/粘贴、z-order、分组操作、批量移除与同步均由图表拥有且有界，同步 ID/修订号可防止过期或回显的更新。具名模板是经过校验的样式数据，而不是宿主侧的绘图副本：模板无论在导出时还是应用时，都绝不携带标识（名称、分组、修订号、z-order）、放置（价格比例尺）、可见性（visible、locked、周期可见性）或文本内容（宿主写入的模板中此类键会被丢弃，两种写法均如此），并且分布模板保留目标自身的系列源。V1/V2 持久化保持这些字段为可选，以便无损迁移既有布局；而浏览器/WASM 暴露与原生引擎相同的 schema、模板、对象树与负载操作。

## 仓位网格与统计

Long/Short Position 的创建、主体移动以及入场/目标/止损手柄拖动，会把价格解析到品种的 `tick_size`，若无则回退到所绑定价格比例尺的显示 `min_move`；带有 `PriceTickLadder` 的比例尺则改用其价位带的 tick，因此阶梯式品种的价位保持在其可下单的网格上，价格 tick 数统计按累计的价位带 tick 计数。引擎先把原始的 `f64` 指针坐标直接转换为价格，再舍入到 tick，因此小于一个设备像素的 tick 仍然可以到达。水平方向的创建以及入场/延伸手柄使用垂直十字光标线共用的时间槽解析器，包括其可见范围和隐藏系列规则。主体移动会把指针起始十字光标槽与当前十字光标槽之间的差值应用到每个锚点，保持宽度和抓取偏移，并在槽位变化之间保持不动。未来的空槽位仍可编辑，除非适用显式的数据时间约束。对仓位手柄的键盘微调落在同一网格上（价位落在其 tick 上，宽度落在整数个柱槽位上），而若某次微调会舍入回起始位置，则按按键所指方向前进一个 tick 或一个槽位。方形仓位控件发出一个不透明、以主题色填充的 `RoundRect`，带圆角和吸附到设备像素的内侧边框；所有执行器都接收同一份填充与边框几何。

仓位统计是引擎拥有的窗格 chrome：目标/止损距离、百分比、价格 tick 数、预计账户 Amount，以及由 Open/Closed P&L、Qty 和风险回报比组成的两行块。它们只为主选中的仓位绘制（包括刚放置之后）；未选中的仓位保留其区域、进度叠加层与 Y 轴价格标签，不显示统计。由于这些标签位于保留的 chrome 层，涉及仓位的主选中变化会在帧输入同步时使 chrome 失效（见[帧](../rendering/frame.md)），因此每条选择路径（输入控制器、宿主 API、恢复）都会刷新它们，无需逐次调用失效。经持久化并校验的绘图选项 `position_account_size`（默认 1,000）和 `position_risk_percent`（默认 25）定义一个假设的风险预算。Qty 为该预算除以止损距离和品种点值；数量显示使用品种精度（默认三位小数）。这些估算值不会提交订单，也不会改变以宿主为权威的券商数量。已平仓 P&L 使用与进度叠加层相同的“先触及边界、OHLC 有歧义时止损优先”的区段解析器；未平仓/未成交/未来的绘图使用右边缘处或最近可用的收盘价。零风险或不可用的值显示为长破折号。统计发出不透明、圆角、无边框的容器：对比文本之下的纯色语义填充已经把标签与图表分隔开，因此在任何背景上都不绘制轮廓。文本对比度相对于不透明容器解析。每个执行器都使用这些相同的形状。

## 测量工具与瞬态测量

测量工具是“投影与标注”绘图族（Projection & Annotations，`kinds/projection_annotations.rs`，上游的 wire id 13-15，在族路径上实现）的目录条目，而不是一个单独的子系统。价格范围、日期范围以及日期与价格范围是双锚点的 `ClickAnchors` 工具，其锚点与每个目录工具一样：创建、锚点拖动和主体移动（指针与键盘）会把价格解析到品种 tick 或价格带阶梯（回退到所绑定比例尺的 `min_move`），x 解析到十字光标的时间槽（见[规范状态与工具目录](#规范状态与工具目录)），因此统计值以整根柱和整数个 tick 读出。磁吸命中一根 K 线时，会选择该柱及其价格；磁吸已开启但没有选中任何对象时（弱磁吸且离每个价格都太远，或指针下没有柱，例如在最后一根柱之外），则把槽位和 tick 交给网格，因此锚点绝不会脱离柱位。目录名称是上游的 `date_price_range`；自有线较早的拼写 `date_and_price_range` 在任何解析 kind 名称的地方（持久化导入、模板、剪贴板与同步载荷）都会被读作 `date_price_range`，并且绝不会被写出（旧版名称机制见[旧版工具名与文档迁移](drawing-families.md#旧版工具名与文档迁移)）。

它们与每个族工具一样，经共享的绘图部件转换为图元：半透明填充、清晰的 `HLine` 价格水平线或 `VLine` 时间边界线、穿过区域中心的清晰一像素箭杆（以绘图自己的端帽收尾，`stroke_end` 默认为箭头），以及位于终点价位之外的、由引擎格式化的不透明无边框统计框（日期工具则位于区域下方）。该框显示绘图的可见 `labels`（价格变化、百分比变化和 tick 数；柱数与时长；或全部五项），其中 tick 数按锚点所吸附的网格计数，经过的时间取自锚点的时间标识（在数据之外用当前通行的柱间隔外推），因此它绝不依赖显示投影。绘图输出的每个价格都经过同一个比例尺格式化入口 `format_scale_price`（宿主格式化器、所绑定比例尺的所选格式、tick 网格上的品种精度、该比例尺的系列格式、默认值；见[比例尺价格格式](panes-and-scales.md#比例尺价格格式)），舍入为零的变化不带符号输出。已提交的范围在两个方向上都以绘图自己的颜色绘制。选中或放置期间，它们会把端点投影到坐标轴上，在所绑定比例尺上显示为价格标签，在时间轴上显示为绘图颜色的时间标签（数据之外的锚点显示其外推时间，即统计所使用的那个时间）。当带有可见标签的绘图其区域位于屏幕外时，该族的 `decoration_extent` 使其仍保留在视口候选中。


Shift 点击快速测量是由 `DrawingController` 拥有的瞬态状态：一个绑定到被按下窗格的默认价格比例尺的日期与价格范围，经与已提交范围相同的族部件转换为图元（默认标签与端帽），其锚点按同样的槽位与 tick 规则吸附。由于没有用户样式，其颜色跟随价格走向：上涨时用绘图默认色，下跌时用市场下跌色 token（活动的坐标轴标签随之变化）。存活的测量会在对象命中测试之前消费下一次窗格按下（使跟随中的测量冻结，使已冻结的测量关闭）；否则，在交易、警报、已激活工具、绘图拖动和 Delta Tooltip 的裁决都放弃该次按下之后，引擎输入控制器会由 Shift 按下启动它。终点锚点无论是否按住按钮都跟随指针移动，并被限制在窗格内；超出共享的 5 px 点击容差的释放会冻结按下拖动式测量，而一次点击则使其继续跟随，直到下一次按下。激活工具、按 Escape（`cancel_drawing_tool`）、宿主取消以及持久化恢复都会将其清除。它在末尾的绘图预览块中、于创建预览之后绘制，跟随期间保持十字光标可见并保持其光标，随绘图的逻辑坐标一并重新定基，并且绝不进入绘图列表、历史、同步或持久化。浏览器和 GPUI 适配器把归一化后的输入转发给该控制器，因此所有宿主共用同一个测量状态机。

## 候选查询与工作量边界

绘图工作在帧发出之前就被独立地限定了上界。至多二十个绘图的图表使用直接的、按稳定 z 序的渲染路径，以避免索引开销。更大的图表只扫描被悬停窗格的紧凑边界条目，在坐标计算之前先用语义域排除，在候选列表中保持窗格的规范稳定 z 序，并且只对指针候选执行精确的逐工具命中测试。保留的逐绘图分段按“空闲在下、活动在上”重新组装，提升时无需重建几何；命中测试保持按稳定顺序，因此提升不会使悬停来回振荡。这个有意保持小巧的局部结构不依赖空间树：其廉价的边界遍历与该窗格所拥有的绘图数成线性关系；文本范围每个语义/字体代次只测量一次；坐标转换、笔刷遍历、图元发出和精确命中测试则随候选数量而变化。因此，病态的完全重叠仍然明确地是候选数线性增长的最坏情况。缓存内存受以下各项限定：存活的绘图条目、保留的路径点容量、窗格成员关系，以及一个可复用的候选临时向量；移除会释放该条目，且不保留任何历史几何。
